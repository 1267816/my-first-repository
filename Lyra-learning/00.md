# UE5 Lyra 开发环境搭建与源码验证记录

本文档详细记录了配置虚幻引擎 5.8 (Lyra) C++ 开发环境的完整实操步骤，包括基础编译器安装、IDE 配置、磁盘与内存优化，以及项目的生成、编译与运行验证。

---

## 一、 基础 C++ 开发环境配置

### 1. 安装 MinGW-w64 编译器

用于日常轻量级 C/C++ 程序（如课内 C 语言作业）的编写与运行。

- **下载与解压**：从 WinLibs 下载 `x86_64-posix-seh-gcc-16.2.0` 压缩包，解压至 `C:\mingw64`。
- **环境变量配置**：将 `C:\mingw64\bin` 添加到系统环境变量 `Path` 中。
- **验证结果**：在 CMD 中执行 `g++ --version`，成功输出 GCC 16.2.0 版本信息。

### 2. 安装 Visual Studio 2026

用于构建和编译庞大的虚幻引擎 C++ 源码（MinGW 无法用于编译 UE）。

- **工作负荷勾选**：
  - 勾选 **“使用 C++ 的桌面开发”**（覆盖基础 C++ 开发）。
  - 勾选 **“使用 C++ 的游戏开发”**（UE 必需组件）。
- **单个组件勾选**：额外勾选 **“适用于 Windows 的 Git”**。
- **安装路径**：为避免占用 C 盘，将 IDE 本体、缓存及共享组件全部安装在 `D:\Program Files\Microsoft Visual Studio\...`。

## 二、 系统环境与磁盘优化

### 1. 重定向 UE 缓存 (保护 C 盘)

防止虚幻引擎的派生数据缓存（DDC）耗尽 C 盘空间。

- **操作**：在 D 盘创建文件夹 `D:\UnrealEngineCache`。
- **配置**：新建系统用户变量，变量名为 `UE-LocalDataCachePath`，变量值为 `D:\UnrealEngineCache`。

### 2. 扩大虚拟内存 (防止引擎崩溃)

Lyra 运行时占用内存极大，通过增加虚拟内存防止发生内存溢出闪退。

- **操作**：进入高级系统设置 -> 性能选项 -> 虚拟内存更改。
- **C 盘设置**：设置为“系统管理的大小”。
- **D 盘设置**：取消自动管理，设定自定义大小。初始大小设为 `16384` MB，最大值设为 `32768` MB。点击“设置”并重启电脑生效。

## 三、 项目生成与源码编译

### 1. 修复右键菜单并生成工程文件

- **注册引擎路径**：进入 UE 引擎真实目录 `D:\UE_5.8\Engine\Binaries\Win64`，以管理员身份运行 `UnrealVersionSelector.exe`，提示注册成功（`Registration successful`）。
- **生成 `.sln` 文件**：在 `D:\LyraStarterGame` 目录下，右键 `LyraStarterGame.uproject`，选择 **Generate Visual Studio project files**。

### 2. 使用 VS 编译源码

- **打开工程**：双击生成的 `LyraStarterGame.sln` 进入 Visual Studio 2026。忽略“不支持的组件”等提示。
- **编译配置**：在顶部工具栏，将目标配置设为 **`Development Editor`**，平台设为 **`Win64`**。
- **执行编译**：点击“本地 Windows 调试器”或按 `F5` 开始编译。
- **执行结果**：系统共调度 429 个编译任务。等待编译完成后，虚幻引擎编辑器自动启动。

## 四、 第 0 章官方实验验证

### 实验 1：读取 Experience 加载日志

- **步骤**：在引擎中打开“输出日志 (Output Log)”，搜索 `LogLyraExperience`。在内容浏览器搜索并打开地图 `L_Expanse`，点击 **Play** 运行。
- **结果验证**：日志面板成功打印出 `Identified experience...` 和 `StartExperienceLoad...`，确认底层玩法加载机制正常运行。

### 实验 2：从蓝图追溯 C++ 父类

- **追溯 GameMode**：打开蓝图 `B_LyraGameMode`，在“类设置”中确认其父类为原生 C++ 类 `Lyra Game Mode` (即 `ALyraGameMode`)。
- **追溯 Character 继承链**：打开蓝图 `B_Hero_ShooterMannequin`，通过“类设置”逐级向上检查父类（`B_Hero_Default` -> `Character_Default`），最终追溯至原生 C++ 类 `ALyraCharacter`。
- **结论验证**：理解了 UE 中 C++ 构建底层逻辑，蓝图类负责具体资产配置的继承体系。
