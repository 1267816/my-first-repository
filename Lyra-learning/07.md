# 7-1 实操记录：往所有 LyraCharacter 上注入组件

## 🎯 实验目的

验证 Add Components 对“现有的 + 将来的、服务器 + 客户端”的 Pawn 都生效。

## 🛠️ 实操步骤（我做了什么）

1. 新建 `BP_HelloComponent`（父类 Actor Component），在 BeginPlay 打印 Owner 名 + authority 状态。
2. 复制 `B_ShooterGame_Elimination` 为 `B_MyElimination`，在 Actions 添加 `Add Components`（LyraCharacter -> BP_HelloComponent，Client/Server 都勾选）。
3. Project Settings 中设置 `Experience Override` = `B_MyElimination`。
4. PIE 选 `Play As Client`、2 玩家、在 `L_ShooterGym` 运行。

## 📊 运行结果

在输出日志过滤 `authority`，得到以下结果：

- `Server: B_Hero_ShooterMannequin_C_0~3 authority=true` (4个)
- `Client 1: B_Hero_ShooterMannequin_C_0~3 authority=false` (4个)
- `Client 2: B_Hero_ShooterMannequin_C_0, C_2, C_4 authority=false` (3个)

## 🧠 结论与总结

1. 现象完全符合预期：服务器世界里场上每个 Pawn 都有组件（authority=true）；客户端世界里能看到的每个 Pawn 也都有组件（authority=false）。
2. 印证原理：Add Components 会在每个世界（服务器+各个客户端）独立提交一次请求，非复制组件在每一端各自创建一份。
3. 避坑：联网状态下客户端没有权威，只能接收服务器的指令；网络相关范围会导致不同客户端看到的角色数量有微小差异。
