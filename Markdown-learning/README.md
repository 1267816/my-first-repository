## 记录一处踩坑：中文标题的页内跳转

`[文字](#锚点)` 的目标是标题自动生成的 id，而不同渲染器给同一个标题生成的 id 可能不同：

- GitHub：标点直接删除，`# 一、基本语法` 的 id 是 `一基本语法`
- Markdown Preview Enhanced：`、` 会被替换成连字符，同一个标题的 id 是 `一-基本语法`

因此同一个链接在两边不一定都能跳（部分渲染器点不到目标时不会报错，表现为没有反应）。
如果需要跨渲染器都能跳转，给标题加一个显式锚点再链接到它比较稳妥：

```markdown
# 一、基本语法
<a id="top"></a>

[回到大标题](#top)
```
