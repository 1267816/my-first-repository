### 当前版本 V0.1.5（2026-10-12 19:34）—— 已经是一个"能完整走完"的游戏

**一盘大约 15~20 分钟**（用户实测），流程是：

1. 封面 → [ 新游戏 ] → 启动序列（满屏问号 → 「字符解析系统已上线」一次性还原，diegetic 设计）。
2. 新手引导：这台机器告诉你"输入 /mine"；材料到 10 可以 /replicate 复制自己。
3. **第一次复制**触发第一段剧情：解析"附加数据"失败 → 残片 001（人类的遗嘱，暖色）→
   机器把"继续活下去"翻译成"复制自身"。
4. 材料 → 在**科技树**（`/research` 打开）里解锁「简单采集」「批量复制」，命令按钮才出现；
   继续解锁「反应堆」「计算核心」「信号解析」，于是有了**能量 / 算力 / 数据**三种新资源。
5. 科技树同时是**建造台**：解锁后在同一个列表里建造建筑（仓库 / 反应堆 / 计算核心）、
   安装模块（采集助手 / 解析器 / 复制助手）。模块要占**算力槽**，槽不够就空转；
   选中模块按**空格**可以停用 / 启用；算力不够时按"采集助手 → 解析器 → 复制助手"的顺序上线。
6. **星球探测进度**接管剧情节奏：探测器越多越快，覆盖率越接近 100% 越难扫；
   没解锁「长距离通信」时只能扫基地附近（×0.2）。剧情节点按探测 % 触发（实测最大空窗 2 分 25 秒）。
7. **75%** 触发结局线：定位到发射源「回声塔」→ 连接 → 得知广播是一份**没有收件人的遗嘱** →
   命令区出现 [ /stay ]（守墓人）与 [ /go ]（星海漫游，需先研究「星际航行」）→
   结算画面：[ 继续运行 ] / [ 回到选择时刻 ] / [ 返回封面 ]。
   **「回到选择时刻」只回滚经济账、不回收成就**，所以一盘能把两个结局都收齐；100% 还有一句收束。
