### 这个项目有强制的协作规矩（新对话必须遵守，原文在 `AGENTS.md`）

   各迭代一次版本号（`V0.0.x`，与游戏里 `game-data.js` 的 `version` 保持一致）。

4. 保持清晰的项目架构：代码进 `src/`，素材进 `assets/`，md 进 `docs/`；路径改动要同步更新引用。

### 当前版本 V0.1.5（2026-10-12 19:34）—— 已经是一个"能完整走完"的游戏

**一盘大约 15~20 分钟**（用户实测），流程是：

1. 封面 → [ 新游戏 ] → 启动序列（满屏问号 → 「字符解析系统已上线」一次性还原，diegetic 设计）。
2. 新手引导：这台机器告诉你"输入 /mine"；材料到 10 可以 /replicate 复制自己。
3. **第一次复制**触发第一段剧情：解析"附加数据"失败 → 残片 001（人类的遗嘱，暖色）→
   机器把"继续活下去"翻译成"复制自身"。
4. 材料 → 在**科技树**（`/research` 打开）里解锁「简单采集」「批量复制」，命令按钮才出现；
   继续解锁「反应堆」「计算核心」「信号解析」，于是有了**能量 / 算力 / 数据**三种新资源。
5. 科技树同时是**建造台**：解锁后在同一个列表里建造建筑（仓库 / 反应堆 / 计算核心）、
   安装模块（采集助手 / 解析器 / 复制助手）。模块要占**算力槽**，槽不够就空转；
   选中模块按**空格**可以停用 / 启用；算力不够时按"采集助手 → 解析器 → 复制助手"的顺序上线。
6. **星球探测进度**接管剧情节奏：探测器越多越快，覆盖率越接近 100% 越难扫；
   没解锁「长距离通信」时只能扫基地附近（×0.2）。剧情节点按探测 % 触发（实测最大空窗 2 分 25 秒）。
7. **75%** 触发结局线：定位到发射源「回声塔」→ 连接 → 得知广播是一份**没有收件人的遗嘱** →
   命令区出现 [ /stay ]（守墓人）与 [ /go ]（星海漫游，需先研究「星际航行」）→
   结算画面：[ 继续运行 ] / [ 回到选择时刻 ] / [ 返回封面 ]。
   **「回到选择时刻」只回滚经济账、不回收成就**，所以一盘能把两个结局都收齐；100% 还有一句收束。

- **文档里的时间必须是真实时间**（先 `Get-Date`）。上一轮我编了时间戳，用户明确不满。
- **文档时序**：每轮迭代写在自己的小节里，末尾留一行 `回复：` 给用户 —— 别把内容写到 `回复：` 之后。

- **科技的效果文字以数据表为准**（V0.1.5 起：用户写了就用他写的，代码不会自动追加）；
  **数字的唯一来源**是建筑 / 模块那一行（改数值只改 `numbers` 和模块 / 建筑表）。
- **折叠要连队尾一起折叠**：打字机正在打剧情时，排队中的同组行也要合并，否则剧情打完会突然刷一屏。
- **界面上"状态会自己变"的东西**（资源读数、按钮可用性、列表排序）别用**列表序号**记选中项，
  要用**节点身份**；"自己会涨"的条件（探测进度、成就）必须挂进 tick 检查，不能只挂在玩家动作上。
- 数据里 `wip: true` = 这套系统还没上线（现在没有这样的节点了）；`secret: true` = 悬念节点，效果显示 `???`。

### 已锁定的设计方向（不要推翻，除非用户改主意）

- **界面 = 叙事**：终端就是这台机器自己的控制台（diegetic），不是「套了层皮的菜单」。
  *（注意：**科技树目前是一个独立菜单屏**，这条原则被它打破了 —— 用户已把它列为要改造的问题之一。）*
- **基调**：叙述者是**没有感情的机器**，日志天然是冷的；「人味」来自它与人类遗物的对比，不靠煽情。
- **世界观**：人类已灭绝，地球的自动化系统仍在向宇宙广播一条**没有收件人的信号（遗嘱 + 种子数据）**；
