## 5. 已解决过的问题（新对话不要再重复踩坑）

1. **Dev-C++ 中文只在光标所在行显示**：编辑器字体被设成了 Consolas（无中文字形），
   已改为 **NSimSun（新宋体）**。**不要改回 Consolas。**
2. **中文输出乱码**：UTF-8 源码编译后 Windows 控制台按 GBK 显示。
   已在 Dev-C++ 编译参数和 VS Code 的 `tasks.json` 里加 `-fexec-charset=GBK`。
3. **`height.c` 算错**：`scanf` 格式串里的逗号与提示语的空格不匹配，第二个数读不进去。
   教训：**`scanf` 的格式串必须和实际输入逐字符对应**。
4. **改 `devcpp.ini` 前必须完全关闭 Dev-C++**，否则退出时会用内存里的设置覆盖配置文件。

## 7. 下次可以顺手改进的地方（不着急，等学到对应知识再回头改）

- `04-3.c` 素数统计：现在的写法是"枚举所有乘积对、数到 1 个因数就判为素数"，
  **结果是对的**（含 `1 500` 边界），但每个数都要把 1..N 跑一遍。
  学完第 5 周的 `break` / 标志位后，可以重写成"试除到平方根，找到因数就 break"。
- `04-0.c` 里四层嵌套 `if (a!=b) { if (a!=c) ... }`，第 3 周学的 `&&` 可以直接串成一行。
- `factor.c`（阶乘）有个真实坑：`int` 存不下 13!，`n=13` 输出 1932053504、`n=20` 变负数。
  第 6 周"数据类型"会讲整数范围，届时用 `long long` + `%lld` 解决。
- Git 提交信息可以更具体：把 `Create some files` 这类改成 `week4: 完成水仙花数 04-1`，
  以后回看历史更容易。

### 8.3 学习优先级

详见根目录 README 的"学习路线"一节，这里只记要点：

- **P0（10–12 月）**：C 语言语法收尾（week8–14）+ 算法基础（模拟与枚举、排序、二分、前缀和、
  贪心、栈与队列、递归与递推、简单 DP、质数与取模）+ 刷题（洛谷题单、牛客语法与往届真题、
  每周 1 场 CF Div.4/Div.3）。备赛重点是把前 4–6 题做得又快又稳。
- **P1（寒假）**：数据结构入门（链表、栈、队列、堆、并查集、树、图的表示与遍历），
  跟寒假训练营同步。
- **P2（大一下）**：CS61B 或 MIT 6.006、离散数学 6.042J；5 月校赛组队。
- **P3（大二起）**：CSAPP → MIT 6.S081 等系统课；继续竞赛的话再补专题（图论、DP 优化等）。

时间投入：工作日 1–1.5 小时（1 道题 + 复习），周末 4–6 小时（整场虚拟赛 + 补题）；
考试周和课程作业优先，别把课内成绩换掉。
