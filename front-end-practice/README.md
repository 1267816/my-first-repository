## 使用方式

用浏览器直接打开任意 `.html` 文件即可，不需要构建步骤。`css/` 和 `js/` 里是部分页面
引用到的样式与脚本。

## 文件命名

文件名开头的数字是学习顺序，点号后面的部分就是这一节的主题，例如 `6.css选择器.html`
是第 6 个练习、内容是 CSS 选择器。
