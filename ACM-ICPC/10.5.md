# 二、你现在最应该学什么

你现在 C 只学到数组，所以**不要急着直接学算法课里一大堆东西**。

你的第一阶段应该是：

### ① 循环

必须非常熟：

```c
for
while
do while
```

尤其是这种题：

- 1～n 求和
- 统计满足条件的数字
- 找最大值/最小值
- 枚举所有可能
- 多组数据处理

你应该做到看到：

> “对于 1 到 n……”

脑子里马上能想到 `for`。

---

### ② 函数

至少熟悉：

```c
int max(int a, int b)
int check(int x)
void solve()
```

虽然新生赛不一定强制要求写很多函数，但函数会让你代码清楚很多。

---

### ③ 字符串

这是**新生赛非常重要的一块**。

把下面这些搞熟：

```c
char s[1005];
scanf("%s", s);

strlen(s);
strcmp(s1, s2);
strcpy(s1, s2);
```

以及最重要的：

```c
s[i]
```

你要能处理：

- 统计字符
- 判断回文
- 大小写转换
- 字符出现次数
- 字符串比较
- 删除/修改某个字符
- 数字字符串处理

---

### ④ 二维数组

例如：

```c
int a[105][105];
```

必须会：

- 矩阵输入
- 矩阵遍历
- 行列统计
- 主对角线/副对角线
- 四周边界
- 找最大值最小值

这类题非常适合新生赛。

---

# 三、然后开始学“最值得学的算法”

对于你这种情况，我给算法排的优先级是：

> **模拟 > 枚举 > 计数 > 排序 > 前缀和 > 二分 > 双指针 > 贪心 > 基础数据结构**

这个顺序非常重要。

---

## 1. 模拟

这是你比赛前必须吃透的。

所谓模拟，就是：

> 题目怎么描述，你就一步一步模拟。

比如：

> 有一个机器人，向上移动 3 次，向左移动 2 次……

你就老老实实写：

```c
x += ...
y += ...
```

新生赛里大量题目，本质就是**把题目翻译成代码**。

---

# 四、最值得你练的题型

你接下来刷题，不要看到一道题就随便做。

最好按照这种顺序刷。

### 第一层：超级基础

做到看到题目基本不用想：

- A+B
- 求最大最小
- 奇偶判断
- 分数计算
- 多个数字统计
- 求和
- 阶乘
- 最大公约数
- 最小公倍数
- 素数判断
- 简单枚举

这层的目的：

> **训练 C 语言熟练度。**

---

### 第二层：数组

重点刷：

- 数组最大值
- 数组最小值
- 数组反转
- 数组去重
- 数组计数
- 查找
- 统计频率
- 排序
- 前缀和

比如：

> 输入 n 个数，求出现次数最多的数。

这实际上就是很典型的新生题。

---

### 第三层：字符串

重点：

- 字符统计
- 回文串
- 字符串反转
- 大小写
- 单词数量
- 字符替换
- 字符串比较

---

### 第四层：简单数学

学这些就够用了：

- 最大公约数
- 最小公倍数
- 质数
- 因数
- 累加
- 模运算
- 快速幂的最基础理解
- 简单排列组合

暂时不用一上来就啃数论。

# 五、你从现在到比赛，可以这样安排

## 第 1～2 周：把 C 语言补到“能打”

这两周不要追求算法。

每天：

**30～45 分钟学 C**

**60～90 分钟做题**

学习顺序：

```text
循环
↓
函数
↓
二维数组
↓
字符串
↓
指针基础
↓
结构体
↓
常用函数/库
```

这里的核心不是“看完课程”。

而是：

> **每学一个东西，马上写 3～5 道题。**

比如今天学字符串：

不要只看老师讲 `strlen()`。

立刻做：

> 输入一个字符串，统计其中数字字符的个数。

再做：

> 判断字符串是否回文。

这样效率会高很多。

# 六、第 3～4 周：进入真正的算法入门

开始学习：

### 排序

一定要懂：

```text
冒泡排序
选择排序
插入排序
```

但重点其实不是让你比赛时自己写排序。

而是理解：

> “排序可以把无序的数据变得有序，从而降低后续处理难度。”

之后再学：

> 排序 + 枚举

> 排序 + 贪心

这是竞赛里非常常见的思路。

---

### 前缀和

这个非常值得学。

比如：

```text
a = 1 2 3 4 5
```

前缀和：

```text
sum = 0 1 3 6 10 15
```

以后遇到：

> 求 [l,r] 的总和

就可以快速处理。

这是你从“纯 C 语言”迈进“算法”的一个非常好的突破口。

---

### 二分

理解一个非常核心的思想：

> **答案具有单调性，所以可以不断砍掉一半。**

新生赛一般不会给你特别变态的二分。

先会：

```text
在有序数组中查找
```

再慢慢理解：

```text
二分答案
```

---

# 七、第 5～6 周：开始练“比赛思维”

这时候你已经不应该只是：

> “学一个知识点 → 做一道对应题。”

而要开始：

> **拿到一道陌生题，自己判断属于什么类型。**

例如：

题目说：

> 给你 n 个数，要求……

你先问：

```text
是不是数组？
↓
要不要排序？
↓
是不是统计次数？
↓
是不是前缀和？
↓
是不是枚举？
```

这个过程非常重要。

真正比赛和普通刷题最大的区别之一就是：

> **没人告诉你“这题应该用什么算法”。**

---

# 八、第 7～8 周：开始模拟比赛

这一阶段特别重要。

你不能一直：

> 做一道题 → 看答案 → 做下一道题。

必须开始做完整模拟。

比如：

**2 小时 5～8 道题**

模拟真实比赛环境：

```text
00:00 开始

先扫所有题
↓
把一眼能做的做掉
↓
遇到不会的先跳
↓
继续下一题
↓
最后回来处理难题
```

你要训练的不是单题能力，而是：

> **比赛策略。**

# 十、最重要的一件事：建立“错题本”

但是不要搞成数学那种长篇大论。

只记录三个东西：

```text
题目：
错误原因：
以后怎么避免：
```

例如：

> 数组下标越界

错误原因：

```text
数组开了 [100]，却访问了 a[100]
```

以后：

```text
n 个数据
下标通常是 0 ~ n-1
```

再比如：

> `scanf` 输入字符串后出现问题

就记录：

> 注意 `%c` 会读取换行符。

这种东西积累 20～30 条以后，你的代码能力会明显提升。

---

# 十一、比赛前一定要练的“低级错误”

新生比赛里非常容易出现：

```text
数组越界
变量没初始化
循环边界写错
int 溢出
scanf 写错
%d / %lld 搞混
少一个大括号
忘记考虑 n=1
忘记考虑全相同
排序后下标写错
```

这些看起来很蠢，但**比赛特别容易因为它们掉分**。

所以你后期训练一定要养成习惯：

### 写完代码后主动想 5 个情况

例如：

```text
最小值
最大值
只有一个
全相同
答案为 0
```

这叫边界测试。

# 十二、关于“要不要现在学 C++”

我的建议是：

### **这次比赛先把 C 练扎实，不要现在立刻转 C++。**

因为你现在最大的瓶颈不是：

> “不会 `vector`。”

而是：

> **不会把题目转换成程序。**

不过，如果学校比赛允许 C++，并且你以后准备认真参加 ICPC，那么**新生赛结束后尽快转 C++**会更舒服。

因为竞赛中 C++ 的：

```cpp
vector
string
sort
map
set
queue
priority_queue
```

会比纯 C 方便很多。

但**现在为了 12 月比赛临时换语言，很容易两边都不熟。**

# 十四、你千万别走这条路

非常多初学者会这样：

```text
C语言 → 链表 → 栈 → 队列 → 树 → 图 → DP → 线段树
```

看起来学了很多。

结果新生赛一看到：

> “给 n 个数……”

还是不会做。

因为**竞赛真正需要的是解题能力，而不是知识点收藏。**

你现在宁可：

> **把 100 道简单题做到非常熟**

也不要：

> **看完 10 个高级算法但一道题都不会做。**
