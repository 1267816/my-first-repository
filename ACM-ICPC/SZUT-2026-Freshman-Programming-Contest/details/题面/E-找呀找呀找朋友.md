# E. 找呀找呀找朋友

- 时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒
- 空间限制：C/C++/Rust/Pascal 256 M，其他语言 512 M
- 64bit IO Format：%lld

## 题目描述

六花想找志趣相投的好朋友一起追番。她想到了一个问题：
有 n 名同学排成一排，用一个正整数表示他们喜欢的番剧，第 i 名同学喜欢的番剧为 a_i。
如果两名同学喜欢的番剧相同，则称他们为一对好朋友。好朋友 (i, j) 和好朋友 (j, i) 被视为同一对好朋友。
对于第 i 和第 j (i < j) 名同学，定义他们之间的距离为 j - i。
六花想知道所有好朋友之间距离的总和。

## 输入描述

第一行输入一个整数 n (1 ≤ n ≤ 100)，表示同学的数量。
第二行输入 n 个整数 a_1, a_2, ..., a_n (1 ≤ a_i ≤ 100)，表示第 i 名同学喜欢的番剧。

## 输出描述

输出一个整数，表示所有好朋友之间距离的总和。

## 示例1

**输入**
```text
5
1 2 1 1 2
```

**输出**
```text
9
```

**说明**
第 1, 3, 4 名同学喜欢的番剧为 1，三对好朋友的距离分别为 2, 3, 1；
第 2, 5 名同学喜欢的番剧为 2，他们的距离为 3。
距离的总和为 2 + 3 + 1 + 3 = 9。

## 示例2

**输入**
```text
1
1
```

**输出**
```text
0
```
