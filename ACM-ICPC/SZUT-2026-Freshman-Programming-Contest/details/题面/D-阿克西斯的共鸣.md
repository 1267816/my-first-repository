# D. 阿克西斯的共鸣

- 时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒
- 空间限制：C/C++/Rust/Pascal 256 M，其他语言 512 M
- 64bit IO Format：%lld

## 题目描述

U.C.0093 年，小行星阿克西斯在夏亚的计划下向地球坠落。在紧要关头，传奇驾驶员阿姆罗驾驶 ν 高达，和双方阵营的 MS（机动战士）一起尝试用 MS 的推力将阿克西斯推离地球。ν 高达携带着精神感应框架，能把周围所有 MS 的推力连成一体：每台 MS 都能借到左右相邻那两台各一半的推力。

n 台 MS 按输入顺序顺时针围成一个首尾相接的圆环。
每台 MS 的功率由题目给出，其推力等于左右相邻两台 MS 功率的一半的和加上自身功率。
求所有 MS 的推力之和。
保证答案小于 10^6。

## 输入描述

第一行输入一个整数 n (3 ≤ n ≤ 200)，表示 MS 的数量。
第二行输入 n 个整数 v1, v2, ..., vn (0 ≤ vi ≤ 10000)，表示圆环上每台 MS 的功率。

## 输出描述

输出一个整数，表示所有 MS 的推力之和。
可以证明答案一定是整数。

## 示例1

**输入**
```text
5
100 80 120 90 110
```

**输出**
```text
1000
```

**说明**
五台 MS 围成圆环，逐台计算推力：
- 第 1 台 MS：100 + 110/2 + 80/2 = 195；
- 第 2 台 MS：80 + 100/2 + 120/2 = 190；
- 第 3 台 MS：120 + 80/2 + 90/2 = 205；
- 第 4 台 MS：90 + 120/2 + 110/2 = 205；
- 第 5 台 MS：110 + 90/2 + 100/2 = 205。
推力之和为 195 + 190 + 205 + 205 + 205 = 1000。

## 示例2

**输入**
```text
4
10 15 20 25
```

**输出**
```text
140
```
