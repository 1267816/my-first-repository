# C. 红石比较器

- 时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒
- 空间限制：C/C++/Rust/Pascal 256 M，其他语言 512 M
- 64bit IO Format：%lld

## 题目描述

你是一只可爱的红石比较器~
作为一名认真工作的红石比较器，你需要根据自己的工作模式和输入，输出对应的红石信号。

你有一个主输入端和两个侧输入端。设主输入端的信号强度为 a，左、右两个侧输入端的信号强度分别为 b 和 c。面对两侧同时传来的信号，你只在意更强的那一个。也就是说，侧输入信号强度 s = max(b, c)。

你有两种工作模式：
- 比较模式：如果侧输入信号没有超过主输入信号，即 s ≤ a，就输出信号强度 a；否则，输出信号强度 0。
- 作差模式：用主输入信号减去侧输入信号，但结果不能为负数。因此，输出信号强度为 max(a - s, 0)。

现在，你会收到自己的工作模式和三个输入端的信号强度。快来算算应该输出多强的红石信号吧！

## 输入描述

第一行输入一个整数 m (m ∈ {0, 1})，0 表示比较模式，1 表示作差模式。
第二行输入三个整数 a, b, c (0 ≤ a, b, c ≤ 15) 分别表示主输入端、左侧输入端和右侧输入端的信号强度。

## 输出描述

输出一个整数，表示你最终输出的红石信号。

## 示例1

**输入**
```text
0
10 6 8
```

**输出**
```text
10
```

**说明**
两个侧输入中更强的信号强度为 8，你正处于比较模式，因为 8 ≤ 10，所以你会直接输出主输入信号强度 10。

## 示例2

**输入**
```text
0
5 7 3
```

**输出**
```text
0
```

**说明**
两个侧输入中更强的信号强度为 7，你正处于比较模式，因为 7 > 5，侧输入信号超过了主输入信号，所以你输出的信号强度为 0。

## 示例3

**输入**
```text
1
12 4 9
```

**输出**
```text
3
```

**说明**
两个侧输入中更强的信号强度为 9，你正处于作差模式，因此输出信号强度为 max(12 - 9, 0) = 3。

## 示例4

**输入**
```text
1
4 6 10
```

**输出**
```text
0
```

**说明**
两个侧输入中更强的信号强度为 10，你正处于作差模式，不过信号强度不可能为负数，因此输出信号强度为 0。
