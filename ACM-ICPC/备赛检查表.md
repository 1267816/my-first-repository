# 两个月备赛检查表（2026-10-06 → 12 月新生赛）

用法：

- 每完成一项，把 `- [ ]` 改成 `- [x]`（在 GitHub 网页上点右上角铅笔编辑，或在 VS Code / Typora 里直接勾）
- 每阶段分两档：**最少档**是底线，必须做完；**推荐档**是有余力再做的
- 时间默认：工作日 1–1.5 小时（3 道题 + 复盘），周末 4–6 小时（模拟 + 补题）
- 每周日花 30 分钟复盘：这周做完了几项、错题本新增几条、下周补什么

## 通用规则（每道题都适用）

- 做完一道题的标准：① 不看题解能独立写出 ② 过全部样例 ③ 能说出 3 个边界情况
- 错题本只记三行：题目 / 错误原因 / 以后怎么避免
- 写完代码主动想 5 个边界：最小值、最大值、只有一个、全相同、答案为 0
- 低级错误清单见 [README](README.md) 的第七节：数组越界、变量没初始化、`int` 溢出、`%d`/`%lld` 混用等
- 每周日 30 分钟复盘；每周做题 ≥ 15 道（周末模拟另算）
- 每场比赛后 48 小时内完成补题：先自己重做 → 对题解 → 关掉题解重写 → 记进错题本
- 时间冲突时：学校课程与考试优先，宁可少做几道题，也不要欠课内作业
