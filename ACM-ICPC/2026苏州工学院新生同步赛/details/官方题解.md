## B. 请勿食用胀罐棉花糖 题解

每次需要吃 a 分饱，只能吃完整的蘑菇，因此答案为 `ceil((double)a / b)`，直接调用 ceil 函数即可。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
    int a, b;
    scanf("%d%d", &a, &b);
    printf("%d\n", (a + b - 1) / b);
    return 0;
}
```

## C. 红石比较器 题解

先取红石信号的最大值 b = max(b, c) 作为输入信号，再按模式计算：
- 最大值模式：a 变化时，输出 b。
- 减法模式：输出 max(0, a - b)。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
    int m, n, a, b, c;
    char s;
    scanf("%d%d%d%d", &m, &n, &a, &b, &c);
    scanf(" %c", &s);
    int t = max(b, c);
    int ans = 0;
    if (s == 'a') ans = t;
    else if (s == 's') ans = max(a - t, 0);
    printf("%d\n", ans);
    return 0;
}
```

## D. 阿克西斯的共鸣 题解

每台 MS 的功率贡献完算给自己，又贡献一半给左右邻居，总共被计算两次。因此把所有功率求和，再乘 2 即为答案。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
    int n;
    scanf("%d", &n);
    int sum = 0;
    for (int i = 0; i < n; i++) {
        int a;
        scanf("%d", &a);
        sum += a;
    }
    // 每台 MS 的功率在总功率中恰好贡献两次
    printf("%d\n", sum * 2);
    return 0;
}
```

## E. 找呀找呀找朋友 题解

枚举所有可能的位置 i, j (i < j)。如果 a_i = a_j，就把距离 j - i 加入答案。n ≤ 100，直接使用两重循环即可，时间复杂度为 O(n^2)。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
    int n, a[105], ans = 0;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    for (int i = 1; i <= n; i++) {
        for (int j = i + 1; j <= n; j++) {
            if (a[i] == a[j]) ans += j - i;
        }
    }
    printf("%d\n", ans);
    return 0;
}
```

## F. 晨跑打卡 题解

从左到右扫描，维护当前连续打卡成功的天数。若 a_i ≥ k 天数计数器加一，否则清零。扫描过程中出现的最大计数就是答案。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
    int n, k, a, cnt = 0, ans = 0;
    scanf("%d%d", &n, &k);
    for (int i = 0; i < n; i++) {
        scanf("%d", &a);
        if (a >= k) cnt++;
        else cnt = 0;
        ans = max(ans, cnt);
    }
    printf("%d\n", ans);
    return 0;
}
```

## G. 寻找数字之神 题解

判断 m 中是否有相邻两位组成 n。每次用 m % 100 取后两位，再用 m /= 10 去掉末位，检查所有相邻数，找到则输出 YES，否则输出 NO。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
    int m, n;
    scanf("%d%d", &m, &n);
    while (m > 10) {
        if (m % 100 == n) {
            printf("YES\n");
            return 0;
        }
        m /= 10;
    }
    printf("NO\n");
    return 0;
}
```

## H. 第五人格模仿者启动！ 题解

假设有 k 位侦探，那么说“有 k 位侦探”的人全部说真话，其余人全部说假话。因此，数字 k 恰好出现 k 次，这个答案就是 k。

统计每个数字的出现次数，输出任意满足 `cnt[k] = k` 的 k。

```cpp
#include<bits/stdc++.h>
using namespace std;
int cnt[1005];
int main() {
    int n, x;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &x);
        cnt[x]++;
    }
    for (int i = 1; i <= n; i++) {
        if (cnt[i] == i) { // 出现次数与说真话人数匹配
            printf("%d\n", i);
            return 0;
        }
    }
    return 0;
}
```

## I. 快速夺取 题解

仓库只有两行，故障的情况只有两种：同一列上下都有机器人，或者两行在同向移动的人，可以分别从另一边绕行。

设较远目标列的编号为 m = max(c1, c2)，只有前 m 列的位置均可用，才能成功到达目标。否则输出 NO；否则两处目标都能到达。

时间复杂度 O(n)。

```cpp
#include<bits/stdc++.h>
using namespace std;
int a[2][105];
int main() {
    int n, c1, c2;
    scanf("%d%d", &n, &c1, &c2);
    int t1, t2;
    scanf("%d%d", &t1, &t2);
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < 2; j++) {
            scanf("%d", &a[j][i]);
        }
    }
    int m = max(c1, c2);
    for (int j = 0; j <= m; j++) {
        if (a[0][j] && a[1][j]) { // 同一列上下都有机器人，无法绕行
            printf("NO\n");
            return 0;
        }
    }
    printf("YES\n");
    return 0;
}
```

## J. 争夺数字之神 题解

数字为 3 的倍数时先手必败，否则先手必胜。

先手可以取 1 或 2 使剩余数字成为 3 的倍数。之后对手取 1 颗，你取 2 颗；对手取 2 颗你取 1 颗，每轮共取 3 颗，保证自己抢到最后一颗。

因此，当 n % 3 == 0 输出 NO，否则输出 YES。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
    int n;
    scanf("%d", &n);
    if (n % 3 == 0) printf("NO\n");
    else printf("YES\n");
    return 0;
}
```

## K. 三角符文扑克谜题 题解

插入操作必须进行 n 次，相邻两张图案不同，它们的插入至少需要翻转一次；相邻两张图案相同，它们的插入至少需要翻转一次。因为第一张和最后一张的图案不同，所以答案为：n + 相邻不同的对数 + [a_1 == a_n]。

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
    int n;
    char s[105], ans;
    scanf("%d", &n);
    scanf("%s", s + 1);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    int ans = n;
    for (int i = 1; i < n; i++) {
        if (s[i] != s[i+1]) ans++;
    }
    if (s[1] == s[n]) ans++;
    printf("%d\n", ans);
    return 0;
}
```

## L. 无尽咔咔 (Easy Version) 题解

### 算法

维护当前生命值 h 和攻击次数 a。第 i 回合先以 a + 1 更新答案，计算可能发生的致死攻击后，若 h > a 则攻击，否则回血。当 h < i 时，若继续攻击，则该回合必死，无法继续。

该贪心可由交换论证证明。当 h > i 而最优策略选择回血时，必然不会致死。将回血与后续攻击交换，之后回血量会改为在当前回合后立即回血，与之前的最优策略相比，回血总量不变，攻击次数不变，且可以多输出一次攻击，不会更劣。

总时间复杂度为 O(n + q)，空间复杂度为 O(1)。

### 示例代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
    int n, q;
    scanf("%d%d", &n, &q);
    int h = 0, a = 0, ans = 0;
    for (int i = 0; i < n; i++) {
        int x, y;
        scanf("%d%d", &x, &y);
        if (x == 1) {
            ans = max(ans, a + 1);
        } else {
            ans = max(ans, a + 1);
            h += y;
        }
        if (h > i) {
            a++;
        } else {
            h = i;
        }
    }
    printf("%d\n", ans);
    return 0;
}
```

## M. 无尽咔咔 (Hard Version) 题解

### 算法

记 `f(t) = t - (t - 1) / k`，则 `f(t)` 表示当有 t 次攻击时，第 t 回合后剩余的生命值。

因此，最少需要 `g(x) = x - f(x) + 1` 次攻击，最大攻击次数为 `r(t) = max(0, t - f(t) + 1)`。

最终，当 `f(t - 1)` 小于等于当前生命值，且 `f(t)` 大于当前生命值，即 `t = g(x)` 时，在第 t 回合，当前生命值变为 0，死亡。此时用公式求得结果。

由于 f 和 g 的值域在 [1, n] 范围内，且 k > 1，因此这种 f 和 g 的变换是唯一的，满足要求的 t 的区间为 [1, n]。

当 s[i] == '0' 时，即 t 为 0，此时输出 0。

时间复杂度为 O(log K)，空间复杂度为 O(1)。

### 示例代码

```cpp
#include<bits/stdc++.h>
typedef long long ll;
using namespace std;
ll n, k;
ll g(ll x) {
    if (x <= 0) return 0;
    ll l = 1, r = n, mid;
    while (l < r) {
        mid = (l + r) / 2;
        if (mid - (mid - 1) / k >= x) r = mid;
        else l = mid + 1;
    }
    return l;
}
int main() {
    scanf("%lld%lld", &n, &k);
    char s[100005];
    scanf("%s", s + 1);
    ll q;
    scanf("%lld", &q);
    for (int i = 1; i <= q; i++) {
        ll x;
        scanf("%lld", &x);
        printf("%lld\n", g(x));
    }
    return 0;
}
