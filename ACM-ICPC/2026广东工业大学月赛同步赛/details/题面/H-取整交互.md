# H. 取整交互（本题暂无数据，请勿提交）

> 整理标注：本题在牛客上暂不支持交互题评测，官方题解也标为「暂无数据」。题面保留备查。

## 题目描述

本题是一道交互题，选手的程序可以向交互器进行若干次询问，最后提交答案。具体交互方式请参考下方交互协议部分。

交互器隐藏了一个整数 n (10⁹ ≤ n ≤ 10¹⁸)。

为了确定这个整数，你可以进行询问。每次询问，你选择一个整数 k (10⁹ ≤ k ≤ 10¹⁸)，交互器会返回 ⌊n/k⌋，即 n 除以 k 后向下取整的结果。

请使用不超过 32 次询问，确定隐藏的整数 n。

## 输入描述

本题没有初始输入。你的程序应先发出询问，再读取交互器的回答。

## 输出描述

隐藏的整数 n 在交互开始前确定，并且在整个交互过程中保持不变。

- 要进行一次询问，输出一行，格式如下：

  ```text
  ? k
  ```

  其中 k 是一个整数，满足 10⁹ ≤ k ≤ 10¹⁸。输出询问后，从标准输入读取一个整数 q，表示交互器的回答，其中 q = ⌊n/k⌋。

- 当你确定隐藏的整数后，输出一行，格式如下：

  ```text
  ! n
  ```

  其中 n 是你求出的答案。输出后刷新输出缓冲区，并立即结束程序。

注意：你最多可以进行 32 次形如 `? k` 的询问。形如 `! n` 的最终答案不计入询问次数。

每次输出询问或最终答案后，都必须输出换行符并刷新输出缓冲区，否则可能得到 `Idleness Limit Exceeded` 判定。可以使用以下方式刷新缓冲区：

- C/C++：使用 `fflush(stdout)` 或 `cout.flush()`；
- Java：使用 `System.out.flush()`；
- Pascal：使用 `flush(output)`；
- Python：使用 `sys.stdout.flush()`，也可以在输出时使用 `print(..., flush=True)`；
- 其他语言：请查阅相应语言的标准输出刷新方法。

**输入**
```text
NaN
```

**输出**
```text
NaN
```
