# F. 猪猪的难题

## 题目描述

定义一个非空字符串的 `权值` 为其出现过的不同小写英文字母的种类数，记为 w(T)。

给定一个长度为 n 的小写英文字母字符串 S，字符串下标从 1 开始编号。

你需要回答 q 次询问。每次询问给定两个整数 l, r，你需要计算：

```text
Σ (l ≤ i ≤ j ≤ r) w(S_i S_{i+1} … S_j)
```

换句话说，对于区间 [l, r] 对应的子串，需要枚举其中所有非空连续子串，并求这些子串权值的总和。

## 输入描述

- 第一行一个整数 T (1 ≤ T ≤ 1000)，表示数据组数。
- 对于每组数据：
  - 第一行两个整数 n, q (1 ≤ n, q ≤ 10⁶)，分别表示字符串长度和询问次数。
  - 第二行一个长度为 n 的小写英文字母字符串 S。
  - 接下来 q 行，每行两个整数 l, r (1 ≤ l ≤ r ≤ n)，表示一次询问。
- 题目数据保证：
  - Σn ≤ 10⁶，Σq ≤ 10⁶。
  - 字符串 S 仅由小写英文字母组成。

## 输出描述

对于每组数据，输出一行 q 个整数，依次表示该组数据中每次查询的答案。

同一行内相邻两个整数之间用一个空格隔开。

## 示例 1

**输入**
```text
1
3 3
abc
1 3
1 1
2 3
```

**输出**
```text
10 1 4
```
