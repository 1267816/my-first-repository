# J. 捕风的异乡人

## 题目描述

旅行者和派蒙接到冒险家协会的委托，前往调查一条出现异常波动的地脉。

整条调查路线上有 n 个节点，第 i 个节点含有能量值为 a_i。

为了布置地脉稳定装置，旅行者需要将整条路线划分成若干个连续区间。设地脉稳定装置的影响参数为 k，则每个区间的长度都必须满足区间长度 ≥ k。

具体地说，假设旅行者选择将路线划为 m 个区间，即这 m+1 个划分点满足：

```text
0 = p_0 ≤ p_1 ≤ … ≤ p_m = n
```

第 t 个区间是 [p_{t−1}+1, p_t]，则合法划分下，每个划分点都必须满足 p_t − p_{t−1} ≥ k。

每个区间都可以尝试启动一次地脉共鸣装置。根据冒险家协会提供的实验记录，如果某个区间内包含的所有节点的元素能量之积是 u 的因子，也就是：

```text
∏ (j = p_{t−1}+1 … p_t) a_j  |  u
```

那么这个区间可以完成一次有效的元素共鸣。请你选择一种合法划分，使可以完成一次有效的元素共鸣的有效区间的数量最大。

## 输入描述

- 第一行包含三个正整数 n, k, u (1 ≤ k ≤ n ≤ 500000，1 ≤ u ≤ 10¹⁸)。
- 第二行包含 n 个正整数 a_1, a_2, …, a_n (1 ≤ a_i ≤ 500000)。

## 输出描述

输出一个整数，表示合法划分中有效区间数量的最大值。

## 示例 1

**输入**
```text
8 3 12
2 2 3 1 2 2 3 5
```

**输出**
```text
1
```

**说明**
n = 8, k = 3，因此最多可以划分为 2 个区间。

- 若只划分为一个区间，所有节点能量值之积为 2 × 2 × 3 × 1 × 2 × 2 × 3 × 5 = 720，720 不是 12 的因子，因此该区间无效。
- 若划分为两个区间，划分点 p_1 只能取 3, 4, 5：
  - p_1 = 3 时，两个区间的乘积分别为 12 和 120，只有第一个区间有效；
  - p_1 = 4 时，两个区间的乘积分别为 24 和 60，均无效；
  - p_1 = 5 时，两个区间的乘积分别为 24 和 30，均无效。

因此最多有 1 个有效区间，答案为 1。
