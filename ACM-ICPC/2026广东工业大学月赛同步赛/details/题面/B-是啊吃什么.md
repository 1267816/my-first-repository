# B. 是啊，吃什么

## 题目描述

结束了紧张刺激的牛客多校，unk 和可爱的队友们感到饥肠辘辘，来到了好口福。

经过一些观察，发现好口福共有 n 个座位，目前有 k 个空位。

unk 能预测到接下来会依次发生 m 个事件。所有事件组成一个长度为 m 的字符串 s：

- 若 s_i = 0，表示一名正在用餐的客人离开餐厅，空位数增加 1。若此时所有座位均为空，则空位数不变；
- 若 s_i = 1，表示一名正在用餐的客人离开餐厅，空位数增加 1。若此时所有座位均为空，则空位数不变。

> 整理标注：上面第二条是题面原文，但结合样例与题意应为「一名新客人到达餐厅，空位数减 1」。整理时保留原文，改动请以牛客题面为准。

unk 拥有一种魔法。每施展一次魔法，可以让一名正在用餐的客人立即暴风吸入食物，立即离开餐厅，立即空出一个座位。

她可以在任意时刻施展魔法。请计算至少需要施展多少次魔法，才能使每一名到达餐厅的客人都可以立即入座，无须等待。

## 输入描述

- 第一行包含一个整数 T (1 ≤ T ≤ 10⁴)，表示测试数据的组数。
- 对于每组测试数据：
  - 第一行包含三个整数 n, k, m (1 ≤ n, m ≤ 10⁶，0 ≤ k ≤ n)，分别表示餐厅的座位数、初始空位数和事件数量。
  - 第二行包含一个长度为 m 的字符串 s。字符串中的每个字符均为 `0` 或 `1`。
- 对于单个输入文件中的所有测试数据，保证 Σn + Σm ≤ 10⁶。

## 输出描述

对于每组测试数据，输出一行一个整数，表示至少需要施展的魔法次数。

## 示例 1

**输入**
```text
3
1 0 3
101
3 2 4
1110
2 2 5
00111
```

**输出**
```text
1
1
1
```
