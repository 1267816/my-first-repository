# I. SBR: 荒野中的觉悟

## 题目背景

Steel Ball Run 大赛仍在继续。

乔尼和杰洛穿过荒野，来到了一座被风沙包围的小镇。这里没有为骑手准备的欢呼，只有一群因悬赏与恩怨聚集的神枪手。

争执最终变成了一场决斗。为了不让任何人占据先拔枪的优势，他们定下了一条规则：

「同一声钟响，一人一发子弹。剩下的，就交给各自的枪法与命运。」

神枪手们围成一圈，手掌缓缓移向枪柄。

杰洛望着眼前的人群，忽然问道：

「乔尼，你觉得...这一轮枪声结束之后，还会多少人站着？」

## 题目描述

有 n 名神枪手，编号为 1, 2, …, n。第 i 名神枪手的命中率为 a_i / 100，其中 a_i 是一个整数。

他们将进行一轮射击，规则如下：

- 每名神枪手从除自己以外的 n−1 人中，等概率随机选择一人作为目标。
- 所有人同时射击，每人只射出一发子弹。即使某人在本轮被击中，他也会完成自己的射击。
- 第 i 名神枪手射出的子弹以 a_i / 100 的概率命中所选目标，否则不会击中任何人。
- 一个人只要被至少一发子弹击中，就会死亡；未被任何子弹击中的人存活。
- 各人的目标选择相互独立，各发子弹是否命中也相互独立，并且与所有目标选择独立。

请你求出这一轮射击结束后，存活人数的期望，并输出其对 998244353 取模的结果。

## 输入描述

- 第一行包含一个整数 T (1 ≤ T ≤ 10⁵)，表示测试数据的组数。
- 对于每组测试数据：
  - 第一行包含一个整数 n (2 ≤ n ≤ 2 × 10⁶)，表示神枪手的人数。
  - 第二行包含 n 个整数 a_1, a_2, …, a_n (0 ≤ a_i ≤ 100，1 ≤ i ≤ n)，其中第 i 名神枪手的命中率为 a_i / 100。
- 保证同一份输入中，所有测试数据的 n 之和不超过 2 × 10⁶。所有输入均为整数。

## 输出描述

对于每组测试数据，输出一行一个整数，表示存活人数的期望对 998244353 取模的结果。

具体地，设期望的最简分数形式为 p/q，其中 q > 0。你需要输出唯一的整数 x，满足：

```text
0 ≤ x < 998244353,   qx ≡ p (mod 998244353)
```

可以证明，在本题的数据范围内，这样的整数一定存在且唯一。

## 示例 1

**输入**
```text
1
3
100 100 100
```

**输出**
```text
249561089
```

**说明**
每个人都有两种目标选择，共有 8 种等概率的选择方案。其中 2 种方案会使所有人死亡，其余 6 种方案恰好有一人存活。因此，存活人数的期望为 3/4，对 998244353 取模后为 249561089。

## 示例 2

**输入**
```text
1
2
25 80
```

**输出**
```text
848507701
```

**说明**
两人只能选择对方作为目标。第一人存活的概率为 1/5，第二人存活的概率为 3/4。因此，存活人数的期望为 19/20，对 998244353 取模后为 848507701。
