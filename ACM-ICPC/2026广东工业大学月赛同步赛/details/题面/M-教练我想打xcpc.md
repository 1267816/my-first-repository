# M. 教练！我想打xcpc!

## 题目描述

广东工业大学 ACM 集训队正在整理区域赛报名信息。共有 n 支队伍。每条记录包含队伍名、赛站名、比赛日期和报名是否成功。

请输出所有报名成功的队伍。每行输出队伍名前加上 `gdut_`，随后输出赛站名和比赛日期。输出行的顺序任意。

## 输入描述

> 整理标注：原始汇总里这一节的正文被误写成了样例说明（「样例中有三支队伍报名成功……」），原文缺失。下面的格式是据样例与官方题解反推的，与你的通过代码（`scanf` 读 `n`，再逐行读三个字符串加一个整数）一致；以牛客题面为准。

- 第一行一个整数 n，表示报名记录的条数。
- 接下来 n 行，每行四个字段：队伍名、赛站名、比赛日期（`YYYY-MM-DD`）、报名是否成功（`1` 成功，`0` 失败）。

## 输出描述

对于每条报名成功的记录，输出一行：

```text
gdut_队伍名 赛站名 比赛日期
```

输出顺序任意。报名失败的记录不输出任何内容。如果没有队伍报名成功，可以不输出任何内容。

## 示例 1

**输入**
```text
3
avemujica shanghai 2026-01-01 1
CRYCHIC wuhan 2026-01-10 0
mygo changchun 2026-02-01 1
```

**输出**
```text
gdut_avemujica shanghai 2026-01-01
gdut_mygo changchun 2026-02-01
```
