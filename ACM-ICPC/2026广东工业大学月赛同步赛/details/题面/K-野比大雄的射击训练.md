# K. 野比大雄的射击训练

## 题目描述

大雄有一个大小为 (2n−1) × (2n−1) 的正方形飞镖盘。行和列均从 1 开始编号，中心格子的坐标为 (n, n)。

飞镖盘由中心向外划分为若干个方形环。中心格子的得分为 n，围绕中心的第一圈共 8 个格子，得分均为 n−1。此后每向外一圈，得分减少 1，最外围格子的得分均为 1。当 n = 1 时，飞镖盘只有一个格子，其得分为 1。

现在有 k 支飞镖落在飞镖盘上，且落点互不相同。给定每支飞镖的落点坐标，请计算它们总得分。

## 输入描述

- 第一行包含两个整数 n 和 k (1 ≤ n ≤ 1000，1 ≤ k ≤ (2n−1)²)。
- 接下来 k 行，每行包含两个整数 x_i 和 y_i (1 ≤ x_i, y_i ≤ 2n−1)，表示一支飞镖落在第 x_i 行、第 y_i 列的格子中。
- 保证所有坐标对 (x_i, y_i) 两两不同。

## 输出描述

输出一个整数，表示所有飞镖的总得分。

## 示例 1

**输入**
```text
3 4
3 3
1 1
2 4
5 3
```

**输出**
```text
7
```

**说明**
当 n = 3 时，飞镖盘的得分为：中心 3、中间环 2、最外环 1。

- 第 1 支落在 (3, 3)，得 3 分；
- 第 2 支落在 (1, 1)，得 1 分；
- 第 3 支落在 (2, 4)，得 2 分；
- 第 4 支落在 (5, 3)，得 1 分。

四支飞镖总得分 7。

> 整理标注：官方题解里这一步写成 `min(x, y, 2n−x, 2n−y) + 1`，按这个式子算样例（n=3、(3,3)）会得到 4 而不是 3。正确写法是坐标先减一：`min(x−1, y−1, 2n−1−x, 2n−1−y) + 1`，等价于 `n − max(|x−n|, |y−n|)`，用样例四个点验算分别得 3/1/2/1，合计 7，与样例一致。
