# G. 智慧大学生猪猪比赛

## 题目描述

小猪参加了智慧大学生猪猪比赛（Intelligent Collegiate Pig Contest，简称 ICPC）。比赛结束后，共有 n 名评委为小猪打分，第 i 名评委的原始评分为 a_i。

组委会将所有评委划分为若干个小组。每名评委恰好属于一个小组，且每个小组至少有两名评委。评委可以自由分组，不受输入顺序限制。

每个小组需要选定一个整数 x，作为组内所有评委的最终评分。对于组内的每名评委 i，均须满足：

```text
|x - a_i| ≤ d
```

不同小组可以选定不同的最终评分。最终评分没有额外的取值范围限制。

小猪的总分为所有 n 名评委的最终评分之和。也就是说，一个有 k 名评委、最终评分为 x 的小组对总分的贡献为 kx。

请你求出小猪能够获得的最大总分。如果无法进行合法的分组，输出 `Impossible`。

## 输入描述

- 第一行包含一个整数 T (1 ≤ T ≤ 10⁵)，表示测试数据的组数。
- 对于每组测试数据：
  - 第一行包含两个整数 n (2 ≤ n ≤ 10⁶) 和 d (0 ≤ d ≤ 10⁹)，分别表示评委人数和允许的最大评分差。
  - 第二行包含 n 个整数 a_1, a_2, …, a_n (0 ≤ a_i ≤ 10⁹)，表示每名评委的原始评分。
- 保证同一个输入文件中所有测试数据的 n 之和不超过 10⁶。

## 输出描述

对于每组测试数据，输出一行。

如果存在合法的分组方案，输出一个整数，表示小猪能够获得的最大总分。

否则，输出 `Impossible`（区分大小写）。

## 示例 1

**输入**
```text
3
4 2
0 1 2 3
3 0
0 1 1
3 2
2 4 6
```

**输出**
```text
12
Impossible
12
```

**说明**
- 第一组：把原始评分为 0, 1 的两名评委分为一组，最终评分均为 2；把 2, 3 分为一组，最终评分均为 4。总分 2+2+4+4 = 12，可以证明这是最大值。
- 第二组：d = 0，只有原始评分相同的评委才能在同一小组。原始评分为 0 的评委无法加入任何合法的小组，因此无解。
- 第三组：将三名评委分为一组，最终评分均为 4，总分为 12。
