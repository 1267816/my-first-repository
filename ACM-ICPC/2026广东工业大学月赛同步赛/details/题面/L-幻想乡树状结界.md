# L. 幻想乡树状结界

## 题目描述

幻想乡发生了异变。

博丽灵梦巡查博丽大结界时，发现结界下方的灵脉被人为打散，变成了 n 个散落在幻想乡各处的魔力结点。编号为 1, 2, …, n。第 i 个结点拥有一个非负整数权值 a_i。

灵梦需要在这些结点之间添加边，使所有结点构成一棵树，为了让灵脉有唯一的流向，需要以 1 号结点（博丽神社所在的结点）作为根。

其中有 k 个结点被标记为关键点。对于每个关键点 v，定义 subtree(v) 为以 v 为根的子树所包含的结点集合，其中包括 v 本身。

为了让封印区域中的魔力彼此抵消，要求构造的树的每个关键点 v 的子树所有节点的异或和等于 0，也就是说，满足：

```text
⊕ (u ∈ subtree(v)) a_u = 0
```

其中 ⊕ 表示按位异或，v 的子树包含结点 v 本身。请你构造一棵满足要求的树。如果不存在合法方案，输出 `-1`。

## 输入描述

- 第一行包含两个整数 n, k。
- 第二行包含 n 个整数 a_1, a_2, …, a_n，其中 a_i 是结点 i 的权值。
- 第三行包含 k 个互不相同的整数 v_1, v_2, …, v_k，表示所有关键点的编号。
- **数据范围**：1 ≤ n ≤ 20，1 ≤ k ≤ n，0 ≤ a_i < 2⁶⁰，1 ≤ v_i ≤ n。

## 输出描述

如果不存在满足条件的树，输出一行 `-1`。

否则输出 n−1 行，每行两个整数 x, y，表示树中存在一条无向边。

如果有多重合法方案任选其一输出即可。

## 示例 1

**输入**
```text
5 2
0 5 5 5 5
2 3
```

**输出**
```text
1 2
2 4
1 3
3 5
```

## 示例 2

**输入**
```text
3 1
1 2 4
2
```

**输出**
```text
-1
```

## 备注

当 n = 1 且 a_1 = 0 时，合法输出为空（因为没有边）；当不存在合法树时才输出 `-1`。
