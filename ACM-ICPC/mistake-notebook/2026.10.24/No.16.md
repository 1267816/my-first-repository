## 题目

### 题目描述

信号站从正整数1开始依次检查并按规则报数。报数规则如下：

1. 如果当前整数x满足以下任意一个条件，则屏蔽不报：x是3的倍数；x的十进制表示中包含数字3。
2. 如果当前整数x不被屏蔽，则它为"正常数"。
3. 设备拥有"回声"机制：记录当前连续屏蔽了多少个数；当遇到一个正常数时，如果之前连续屏蔽次数达到2次或更多，那么这个正常数会被报两次；否则只报一次；报完后（无论报一次还是两次）连续屏蔽次数清零。
4. "回声"也算一次报数。例如数字14会被报两次，则它占用两次报数次数，因为前面12和13屏蔽了两次。

现在给定一个整数N，请求出第N次报出的数是多少。

### 输入格式

输入一行，一个整数N。

### 输出格式

输出一行，一个整数，表示第N次报出的数。

### 样例

输入：

```text
10
```

输出：

```text
14
```

### 样例解释

1报1、2报2、3屏蔽（连续1）、4报3、5报4、6屏蔽（连续1）、7报5、8报6、9屏蔽（连续1）、10报7、11报8、12屏蔽（连续1）、13含3屏蔽（连续2）、14正常且前面连续屏蔽达2次，报两次（第9、10次），所以第10次报出的是14。

### 数据范围

1≤N≤1,000,000

## 提交记录

### 提交1

```c
#include <stdio.h>

int isblocked(int x) {
    int ret=0;
    if (x%3==0) {
        ret=1;
    } else {
        while (x>0) {
            if (x%10==3) {
                ret=1;
            }
            x/=10;
        }
    }
    return ret;
}

int main() {
    int n;
    scanf("%d",&n);
    int i;
    int x=1;
    int cnt=0;
    int blockcnt=0;
    int result;
    while (cnt<n) {
        if (isblocked(x)==0) {
            cnt++;
        } else {
            blockcnt++;
        }
        if (cnt==n) {
            result=x;
            break;
        }
        if ((isblocked(x)==0)&&(blockcnt>=2)) {
            cnt++;
            blockcnt=0;
        }
        if (cnt==n) {
            result=x;
            break;
        }
        x++;
    }
    printf("%d",result);

    return 0;
}
```

判题结果：部分正确（28 ms / 564 KB）

## 复盘

- **错在哪**：`blockcnt`只在"发生回声"时清零，正常数只报一次、没触发回声时忘了清零。于是前面攒下的连续屏蔽次数会带到后面，凭空多出一次回声。最小反例n=6：正确序列是1、2、4、5、7、8，第6次报8；这份代码输出7（3和6各屏蔽一次，累计成2，把7当回声报了两次）。我把前400个n逐一与正确模拟对照过，394个不一致，只有个别凑巧相同。
- **顺带**：`isblocked`每轮调了两次，缓存成一个变量就好；400ms限制下影响不大，但没必要。
- **怎么避免**：状态机里每段处理完都要显式重置相关状态（这里就是"报完就清零"，不管报一次还是两次）；写完先拿n=1~20与暴力模拟对照，比盯着样例看管用。
