## 题目

BowTen 是众所周知的大 boss，Zeoy 想要打败 BowTen，但是 BowTen 有 n 个分身，每个分身有 a[i] 的实力，且每个分身实力不同，Zeoy 准备对其分身由弱到强的进行挑战，请你帮 Zeoy 分析一下挑战的顺序。

输入格式：

第一行包含一个整数 t（1≤t≤100）表示测试样例的数量。
对于每个测试样例：第一行包含一个整数 n（1≤n≤2·10^5）表示 BowTen 分身的数量；第二行包含 n 个整数 a[1],…,a[n]（1≤a[i]≤10^9）表示每个分身的实力。保证两两之间都不相同，且所有测试样例中 n 的总和不超过 2·10^5。

输出格式：

对于每个测试样例，输出 n 个数字表示被挑战的分身编号。

输入样例：

```text
2
5
5 3 2 4 1
6
10 2 8 3 5 4
```

输出样例：

```text
5 3 2 4 1
2 4 6 5 3 1
```

### 提交1

```c
#include <stdio.h>

int main(void) {
    int t;
    scanf("%d",&t);

    int i,j,k;
    for (i=0;i<t;i++) {
        int n;
        scanf("%d",&n);
        int a[n];
        for (j=0;j<n;j++) {
            scanf("%d",&a[j]);
        }
        int b[n];
        int min=1000000001;
        for (j=0;j<n;j++) {
            for (k=0;k<n;k++) {
                if (a[k]<min) {
                    min=a[k];
                    b[j]=k+1;
                }
            }
            a[b[j]-1]=1000000001;
            min=1000000001;
        }
        for (j=0;j<n;j++) {
            printf("%d",b[j]);
            if (j==n-1) {
                printf("\n");
            } else {
                printf(" ");
            }
        }
    }

    return 0;
}
```

## 复盘

- **错在哪**：每次挑最小值用双重循环（选择排序），单个测试样例要 O(n²) 次比较。本题所有测试样例的 n 加起来能到 2·10^5，最坏就是 4·10^10 次比较，3000 ms 内做不完，所以超时。
- **正确思路**：这题要的只是「按实力从小到大输出分身的原编号」，本质是排序——把每个分身的（实力，编号）绑在一起按实力升序排，再顺序输出编号，O(n log n)。样例1里 5 3 2 4 1 的实力升序是 1(5号) 2(3号) 3(2号) 4(4号) 5(1号)，正好输出 5 3 2 4 1。
- **怎么避免**：看到 n 上限到 10^5、又要按顺序输出，先想排序；O(n²) 只在 n 到几千时才敢用。写完先按上限估一遍运算量，再看要不要换算法。
