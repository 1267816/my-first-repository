## 题目

### 题目描述

庄园中正在进行一场模仿者游戏。游戏中有 n 位玩家，每位玩家都只可能属于侦探团阵营或模仿者阵营。侦探团阵营的玩家永远说真话，模仿者阵营的玩家永远说假话。保证至少存在一位侦探团阵营的玩家。
每位玩家都会说一句话：“我们有 x 位侦探团阵营的玩家。”现在给出每位玩家所说的 x，请你帮助庄园主确定侦探团阵营的玩家数量。
保证存在满足上述所有条件的阵营划分。

### 输入描述

第一行输入一个整数 n (2 ≤ n ≤ 1000)，表示玩家数量。
第二行输入 n 个整数 x1, x2, ..., xn (1 ≤ xi ≤ n)，表示每位玩家所说的数字。

### 输出描述

输出一个整数，表示侦探团阵营的玩家数量。
如果存在多种可能，您可以输出任意一个，系统会自动判定是否正确。注意，自测运行功能可能因此返回错误结果，请自行检查答案正确性。

### 示例1

**输入**
```text
2
1 2
```

**输出**
```text
1
```

### 示例2

**输入**
```text
3
3 3 3
```

**输出**
```text
3
```

### 示例3

**输入**
```text
4
3 1 3 3
```

**输出**
```text
3
```

**说明**
对于本样例，输出 1 或 3 都将被视为答案正确。

#include <stdio.h>
int main()
{
    int n;
    scanf("%d",&n);
    int x[n];
    int ischecked[n+1];

    int i;
    for (i=1;i<n+1;i++) {
        ischecked[i]=0;
    }
    for (i=0;i<n;i++) {
        scanf("%d",&x[i]);
    }

    int cnt;

    for (i=0;i<n;i++) {
        if (ischecked[(x[i+1])]==0) {
            ischecked[(x[i+1])]=1;
            cnt=0;
            for (int j=0;j<n;j++) {
                if (x[i]==x[j]) {
                    cnt++;
                }
            }
            if (x[i]==cnt) {
                printf("%d",cnt);
                break;
            }
        }
    }

    return 0;
}

## 复盘

- **错在哪**：第一版声明了 int x[n]（只有 0..n-1 合法），循环里却访问 x[i+1]，读到数组末尾之外，判了段错误；第二版改成 x[i]，六分钟后通过。同一版里还声明了 ischecked[n+1]，但初始化只跑到 1..n，也是越界的隐患。
- **代价**：只有 8 分钟，是这一场里处理最快的一次自救。
- **怎么避免**：变长数组只开 n 个元素，合法下标就是 0..n-1；循环条件写 i<n 时，体内不允许出现 x[i+1] 这种「多一位」的访问。写完对每个数组标一遍合法下标区间，比事后调试快得多。
