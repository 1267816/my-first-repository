## 题目

### 题目描述

U.C.0093 年，小行星阿克西斯在夏亚的计划下向地球坠落。在紧要关头，传奇驾驶员阿姆罗驾驶 ν 高达，和双方阵营的 MS（机动战士）一起尝试用 MS 的推力将阿克西斯推离地球。ν 高达携带着精神感应框架，能把周围所有 MS 的推力连成一体：每台 MS 都能借到左右相邻那两台各一半的推力。

n 台 MS 按输入顺序顺时针围成一个首尾相接的圆环。
每台 MS 的功率由题目给出，其推力等于左右相邻两台 MS 功率的一半的和加上自身功率。
求所有 MS 的推力之和。
保证答案小于 10^6。

### 输入描述

第一行输入一个整数 n (3 ≤ n ≤ 200)，表示 MS 的数量。
第二行输入 n 个整数 v1, v2, ..., vn (0 ≤ vi ≤ 10000)，表示圆环上每台 MS 的功率。

### 输出描述

输出一个整数，表示所有 MS 的推力之和。
可以证明答案一定是整数。

### 示例1

**输入**
```text
5
100 80 120 90 110
```

**输出**
```text
1000
```

**说明**
五台 MS 围成圆环，逐台计算推力：
- 第 1 台 MS：100 + 110/2 + 80/2 = 195；
- 第 2 台 MS：80 + 100/2 + 120/2 = 190；
- 第 3 台 MS：120 + 80/2 + 90/2 = 205；
- 第 4 台 MS：90 + 120/2 + 110/2 = 205；
- 第 5 台 MS：110 + 90/2 + 100/2 = 205。
推力之和为 195 + 190 + 205 + 205 + 205 = 1000。

### 示例2

**输入**
```text
4
10 15 20 25
```

**输出**
```text
140
```

            vs=2*v[0]+v[1]+v[n-1];

            vs=2*v[n-1]+v[n-2]+v[0];
        } else {
            vs=2*v[i]+v[i-1]+v[i+1];
        }
        sum+=(vs/2);
    }

    printf("%d",sum);

    return 0;
}

## 复盘

- **错在哪**：18:35 到 18:42 七分钟内连交三次都答案错误，三次都在逐台处理「自己算一次、再分一半给左右邻居」，功率是奇数时 a/2 把那一半直接截断了。之后怀疑数据溢出，把 int 换成 long long、又改用 malloc 重开数组，都没碰到真正的错——这题根本不用逐台分摊：每台 MS 的功率在总量里恰好出现两次，把所有功率加起来乘 2 就是答案。20:30 第四次改成求和再乘 2 才通过。
- **代价**：首交到通过隔了 115 分钟，三次错误提交带来 60 分钟罚时，期间只顺带做了 E、F、G、H，I–M 五题全空。
- **怎么避免**：遇到「贡献被重复计算」的题，先在纸上把总量写成一行式子（求和 × 2），再写代码；任何 a/2 之前先问会不会截断奇数。连错三次时应该先停下改思路，而不是换数据类型。
- **顺带**：三次里的 malloc 没有 include <stdlib.h>，C 会隐式声明成返回 int，64 位下有隐患。
