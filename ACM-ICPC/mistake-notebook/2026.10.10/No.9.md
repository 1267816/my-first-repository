## 题目

### 题目描述

FuFuFu 在玩三角符文时被扑克谜题难住了，由于 FuFuFu 是解谜低手，他希望你能帮助他解决这道谜题。

谜题要求你构造一个由 n 块图案构成的目标序列，目标序列中只会有黑桃和梅花两种图案，分别用 1 和 0 表示。
一开始，你有一个空序列，你可以对它执行以下两种操作任意次：
- 插入操作：在你当前序列的最右边插入黑桃（插入 1）；
- 翻转操作：把你当前序列中所有黑桃变成梅花，梅花变成黑桃（即 1 变成 0，0 变成 1）。

请你告诉 FuFuFu 构造出目标序列最少需要的操作次数。

### 输入描述

第一行输入一个整数 n (1 ≤ n ≤ 100)，表示目标序列的图案数量。
第二行输入 n 个整数 a_1, a_2, ..., a_n (a_i ∈ {0, 1})，表示目标序列的第 i 个图案为 a_i。

### 输出描述

输出一个整数，表示最少需要的操作次数。

### 示例1

**输入**
```text
4
1 1 0 1
```

**输出**
```text
6
```

**说明**
1. 插入 1，序列变为 {1}；
2. 插入 1，序列变为 {1, 1}；
3. 翻转，序列变为 {0, 0}；
4. 插入 1，序列变为 {0, 0, 1}；
5. 翻转，序列变为 {1, 1, 0}；
6. 插入 1，序列变为 {1, 1, 0, 1}。
可以证明不存在操作次数更少的方案。

## 复盘

- **错在哪**：没有提交。构造题看不出「下界」在哪，就没敢动。
- **正确思路**：插入操作本身必须做 n 次，这是底数。相邻两张图案不同时，它们之间至少还要多翻一次；首尾图案相同的话再多一次。答案 = n + 相邻不同图案的对数 + (首尾相同则 1，否则 0)。O(n)。
- **怎么避免**：构造题先找「必然要花的基本操作数」，再找「因为冲突必须额外多做的次数」，两者相加就是下界，这类题的下界往往正好可达——写着就有底气。
