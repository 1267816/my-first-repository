## 题目

### 题目描述

有 n 名同学站成一排。第 i 名同学有一个非负整数标签 a_i。

对于一个连续区间 [l, r]，记 S 为其中出现过的标签组成的集合。mex(S) 表示不属于 S 的最小非负整数。

请你求出所有满足其中标签集合的 mex 不超过 K 的连续区间中，区间长度的最大值。

### 输入描述

- 第一行输入一个整数 T (1 ≤ T ≤ 100)，表示测试数据组数。
- 接下来描述 T 组测试数据。对于每组测试数据，第一行输入两个整数 n 和 K (1 ≤ n ≤ 2 × 10⁵，0 ≤ K ≤ 10¹⁸)，分别表示同学人数和 mex 的上限。
- 第二行输入 n 个整数 a_1, a_2, …, a_n (0 ≤ a_i ≤ n，1 ≤ i ≤ n)，表示每名同学的标签。
- 同一个测试文件中所有测试数据的 n 之和不超过 2 × 10⁵。

### 输出描述

对于每组测试数据，输出一行，包含一个整数，表示满足标签集合的 mex 不超过 K 的连续区间最大长度。请按照输入中的顺序输出每组测试数据的答案。

### 示例 1

**输入**
```text
2
8 2
0 1 2 3 0 2 3 1
5 0
1 2 0 3 1
```

**输出**
```text
5
2
```

### 备注

- 若 S = {0, 1, 2, 3}，则 mex(S) = 4；
- 若区间中的标签为 0, 1, 1, 3，则 S = {0, 1, 3}，因此 mex(S) = 2；
- 若区间中的标签为 1, 2, 3, 3，则 S = {1, 2, 3}，因此 mex(S) = 0。重复出现的标签不会影响 S。

## 复盘

- **错在哪**：一次都没有提交。174/198（88%）的人通过，是这场最不该漏的题。
- **正确思路**：分类讨论。K>n 时整个数组的 mex 也不可能超过 n，答案直接是 n；K≤n 时，窗口里不能同时凑齐 0..K，用双指针滑窗（或记录每个数最后出现的位置）扫一遍求最长区间，O(n)。
- **怎么避免**：这就是阶段 3 的双指针题，不是超纲；看到「最长的区间 + 里面不能同时包含某些数」先想滑窗，再看要不要分类讨论边界。
