# 错题本

## 规则

1. 按做题日期分目录（`YYYY.MM.DD/`），每题一个文件，命名 `No.{序号}.md`。**序号按录入先后递增，跟比赛日期无关**（先录了 10/20、10/21 的四条，后补录 10/10、10/18 两场同步赛的十条），以后不再重排已发出的编号。
2. 收录口径：**做错过的题（哪怕最后通过了）＋ 该做出却没做出来的题**。超纲、当时不在能力范围、比赛里根本没碰的题不收，那些留在赛后复盘分析里逐题记录（例如广工月赛 E、F、G、I、J、L 六道超纲题）。
3. 每个文件固定四段，顺序不变：

   - 顶部信息表：题源、通过情况（拼题A的题写分数与作者）、限制（题面里有就写）、做题日期、结果
   - `## 题目`：题面。保留题目描述、输入输出描述、样例和备注，去掉 OJ 页面上的按钮、作者、提交统计
   - `## 提交记录`：一次提交一节 `### 提交N`，贴当次完整代码，代码块下面一行写 `判题结果：`，原样照抄 OJ 的判定。比赛里没提交过的题，这里写一句"比赛期间没有提交过"
   - `## 复盘`：`错在哪`和`怎么避免`两条；没做出来的题，`错在哪`写当时卡在哪，`怎么避免`换成`正确思路`

4. 复盘只写有依据的东西：能靠提交之间的代码差异确认的才写，猜的不写。用AI做出来的题也要把原理补上，否则等于没做。
5. 每补完一场比赛，先看赛后复盘分析的「逐题诊断」，按第 2 条的口径挑出该收的题，再按顺序往下编号。
