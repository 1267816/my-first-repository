# 第七周：函数

## 7.1 函数的定义和使用

### 7.1.2

**什么是函数**
函数是一块代码，接收零个或多个参数，做一件事情，并返回零个或一个值。
把重复代码封装成函数，能增强可维护性，减少重复的复制粘贴工作。

**函数定义**
```c
void sum(int begin,int end)
{
    int i;
    int sum=0;
    for (i=begin;i<=end;i++) {
        sum+=i;
    }
    printf("%d到%d的和是%d\n",begin,end,sum);
}
```
- 函数头：`void sum(int begin,int end)`
- 函数体：
  ```c
  {
    int i;
    int sum=0;
    for (i=begin;i<=end;i++) {
        sum+=i;
    }
    printf("%d到%d的和是%d\n",begin,end,sum);
  }
  ```
- 函数名：`sum`
- 返回类型：`void`（void表示不返回任何东西）
- 参数表：`(int begin,int end)`，表明sum是一个函数

**调用函数**
- `函数名(参数值);`
- `()`起到了表示函数调用的重要作用，即使没有参数也需要`()`
- 如果有参数，则需要给出正确的数量和顺序，这些值会被按照顺序依次用来初始化函数中的参数

```c
sum(1,10);
sum(20,30);
sum(35,45);
```

在调试时，函数看起来没有进去，实际上已经调用完了。如果要看到调用过程，可以点击“单步进入”按钮。

**函数返回**
函数知道每一次是哪里调用它，会返回到正确的地方。

### 7.1.3

**从函数中返回值**
```c
int max(int a,int b)
{
    int ret;
    if (a>=b) {
        ret=a;
    } else {
        ret=b;
    }
    return ret;
}
```
- return停止函数的执行，并送回一个值
  - `return;`
  - `return 表达式;`
- 一个函数可以有多个return语句，但这样就不符合单一出口的理念

从函数中返回的值可以赋值给变量，可以再传递给函数，甚至可以丢弃。
`max(23,45);`

**没有返回值的函数**
`void 函数名(参数表)`
- 不能使用带值的return，可以没有return
- 调用的时候不能做返回值的赋值

如果函数有返回值，则必须使用带值的return。

### 7.2.1

**函数先后关系**
```c
void sum(int begin,int end)
{
    int i;
    int sum=0;
    for (i=begin;i<=end;i++) {
        sum+=i;
    }
    printf("%d到%d的和是%d\n",begin,end,sum);
}
int main(){
    sum(1,10);
    sum(20,30);
    sum(35,45);

    return 0;
}
```
像这样把sum()写在上面，是因为：
- C的编译器自上而下顺序分析你的代码
- 在看到sum(1,10)的时候，它需要知道sum()的样子，也就是sum()要几个参数，每个参数类型如何，返回什么类型，这样它才能检查你对sum()的调用是否正确

**如果不知道**
也就是要把被调用的函数放到main()下面。
```c
#include <stdio.h>
void sum(int begin,int end);
int main(){
    sum(1,10);
    sum(20,30);
    sum(35,45);

    return 0;
}
void sum(int begin,int end)
{
    int i;
    int sum=0;
    for (i=begin;i<=end;i++) {
        sum+=i;
    }
    printf("%d到%d的和是%d\n",begin,end,sum);
}
```
第2行的`void sum(int begin,int end);`叫做函数的原型声明，`int main(){...}`后面的`void sum(...){...}`叫做函数的定义。
当然，编译到定义之后，还会判断声明和定义的类型是否一致。

**函数原型**
函数头，以分号";"结尾，就构成了函数的原型。
函数原型的目的是告诉编译器这个函数长什么样：
- 名称
- 参数（数量及类型）
- 返回类型


在旧版本的一些C教材中，习惯把在一个函数（如`main()`）中会用到的所有函数的声明写在函数的最顶端，调用的函数中变量的定义也这样写。
原型里可以不写参数的名字，但是一般仍然写上。
如：
`void sum(int ,int );`

### 7.2.2

**调用函数**
如果函数有参数，调用函数时必须传递给它数量、类型正确的值。
可以传递给函数的值是表达式的结果，包括：
- 字面量
- 变量
- 函数的返回值
- 计算的结果

**类型不匹配？**
- 调用函数时给的值与参数类型不匹配是C语言传统上最大的漏洞
- 编译器总是悄悄替你把类型转换好，但是这很可能**不是你所期望的**
- 后续的语言，C++/Java在这方面很严格

**传过去的是什么？**
这样的代码能够交换a和b的值吗？
```c
#include <stdio.h>
void swap(int a,int b);
int main() 
{
    int a=5;
    int b=6;
    swap(a,b);
    printf("a=%d b=%d\n",a,b);
    return 0;
}
void swap(int a,int b)
{
    int t=a;
    a=b;
    b=t;
}
```
结果发现：不能。
C语言在调用函数时，永远只能传值给函数。
swap()里的a和b与main()里的a和b虽然同名，但它们之间的联系仅仅是在调用swap()时把5和6分别传给了swap()里的a和b。

**传值**
每个函数有自己的变量空间，参数也位于这个独立的空间中，和其他函数没有关系。
过去，对于函数参数表中的参数，叫做“形式参数”（swap()里的a和b），调用函数时给的值，叫做“实际参数”（main()里的a和b）。
==实际参数不是实际在函数中计算的参数！！！==
==调用函数的时候传进去的是值不是变量！！！==
