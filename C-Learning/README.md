## 编译与运行

- Dev-C++ 6.3：打开 `.c` 文件后按 F11 编译运行
- 命令行（gcc 已加入 PATH）：

  ```powershell
  gcc 04-0.c -o 04-0.exe -fexec-charset=GBK
  .\04-0.exe
  ```

源码统一用 UTF-8 保存，`-fexec-charset=GBK` 用于让 Windows 控制台正确显示中文；
在不含中文输出的环境下编译可以省略该参数。
