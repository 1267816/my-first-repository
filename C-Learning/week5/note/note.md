# 第五周：循环控制

## 5.1 for循环

### 5.1.1

for循环的**格式**：
```c
for (初始条件;循环继续的条件;循环每轮要做的动作) {
    循环体
}
```
for循环像一个计数循环：设定一个计数器，初始化它，在计数器到达某值之前，重复执行循环体，而每执行一轮循环，计数器值以一定步进进行调整，比如加1或减1。
for循环的读法：
```c
for (count=10;count>0;count--) {
    ...
}
```
上述例子就可以读成：对于一开始的count=10，当count>o时，重复做循环体，没一轮循环在做完循环体内语句后，使得count--。
- **小套路**：做求和的程序时，记录结果的变量应该初始化为0，而做求积的变量时，记录结果的变量应该初始化为1。

在factor.c中，循环控制变量i只在循环里被使用了，循环外面它没有任何用处。因此，我们可以把变量i的定义写到for语句里面去：
- 注意：只有在C99里面才能够使用这种写法。在目前最新版的Dev C++中，已经不用再单独设置选项了，即使这样写也不会报错。
```c
...
for (int i=1;i<=n;i++) {
    fact*=i;
}
...
```
**思考**：
在factor.c中，由于1*1还是1，所以程序的第一个循环没有意义，如果改成2之后，程序对所有的n都正确吗？这样的改动有价值吗？
改动前：
```c
#include <stdio.h>
int main(){
	int n;
	
	scanf("%d",&n);
	
	int fact = 1;
	for (int i=1;i<=n;i++) {
		fact*=i;
	}
	
	printf("%d!=%d\n",n,fact);
	
	return 0;
}
```
将for循环的初始条件i=1改成i=2，当n输入1时，i<=n条件不满足，循环一次都不会进行，此时fact=1，与1!=1的事实符合。
**思考**：
除了可以从1乘到n来计算n!，还可以从n乘到1来计算吧？试试把循环换个方向来计算n。这时候，还需要循环控制变量i吗？
