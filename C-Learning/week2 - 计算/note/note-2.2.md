# 第二周：计算

## 2.2 表达式

**表达式**：
- 一个表达式是一系列运算符和算子的组合，用来计算一个值
```c
amount = x * (1 + 0.033) * (1 + 0.033) * (1 + 0.033);
total = 57;
count = count + 1;
value = (min / 2) * lastValue;
```

**运算符和算子**：
- 运算符（operator）是指进行运算的动作，比如加法运算符“+”、减法运算符“-”
- 算子（operand）是指参与运算的值，这个值可能是常数，也可能是变量，还可能是方法的返回值

**四则运算**：

| 运算 | C 符号 | 意义 |
| --- | --- | --- |
| 加 | `+` | 加 |
| 减 | `-` | 减 |
| 乘 | `*` | 乘 |
| 除 | `/` | 除 |
| 取余 | `%` | 两个数相除以后的余数 |
| 括号 | `()` | 先算括号里的 |

**计算时间差**：
- 题目：分别输入两个时间的小时和分钟，输出两个时间之间的差，也以几小时几分表示
- 如果直接分别减，会出现分钟借位的情况，比如 1 点 40 分和 2 点 10 分
- 办法：先把时间换算成分钟
  - `hour * 60 + minute` 得到以分钟为单位的时间
  - 相减得到差值 t 之后：`t / 60` 是小时部分，`t % 60` 是分钟部分

**求平均值**：
- 输入两个整数求平均值，同样要注意整数除法：想得到小数就要让参与运算的数里有一个是浮点数

**运算符优先级**：

| 优先级 | 运算符 | 运算 | 结合关系 | 举例 |
| --- | --- | --- | --- | --- |
| 1 | `+` `-` | 单目不变 / 单目取负 | 自右向左 | `a * -b` |
| 2 | `*` `/` `%` | 乘、除、取余 | 自左向右 | `a * b` |
| 3 | `+` `-` | 加、减 | 自左向右 | `a + b` |
| 4 | `=` | 赋值 | 自右向左 | `a = b` |

**单目运算符**：
- 只有一个算子的运算符：`+`、`-`
```c
int a = 10;
int b = -20;
printf("%d", a * - b);
```

**赋值也是运算**：
- 赋值也是运算，也有结果：`a = 6` 的结果就是 a 被赋予的值，也就是 6
- 所以可以写 `a = b = 6`，相当于 `a = (b = 6)`
- 这种“嵌入式赋值”不利于阅读，容易产生错误，不推荐这么写

**结合关系**：
- 一般自左向右；单目 `+` `-` 和赋值 `=` 自右向左
```c
result = a = b = 3 + c;
```
- 像下面这样的表达式太复杂，不容易阅读和理解，容易造成读程序时的误解，所以要避免：
```c
result = (result = result * 2) * 6 * (result = 3 + result);
```
- 它应该被拆成若干个表达式，然后以明显、正确的顺序进行计算

**计算复利**：
- 一年期定期利率 3.3%，连续自动转存 3 年，最初存入的 x 元会得到多少本息余额？
- 本息合计 = x(1+3.3%)³
```c
int x;
scanf("%d", &x);
double amount = x * (1 + 0.033) * (1 + 0.033) * (1 + 0.033);
printf("%f", amount);
```
- 要算任意年以后的本息金额，就需要做 (1+0.033)^n 的计算（后面用循环解决）

**交换两个变量**：
- 程序表达的是顺序执行的动作，而不是关系，所以下面两句不是交换，执行完 a 和 b 都会是 b 原来的值：
```c
a = b;
b = a;
```
- 正确做法是引入第三个变量：
```c
int t = a;
a = b;
b = t;
```

**复合赋值**：
- 5 个算术运算符 `+ - * / %` 可以和赋值运算符“=”结合起来，形成复合赋值运算符 `+=`、`-=`、`*=`、`/=` 和 `%=`
- `total += 5;` 等价于 `total = total + 5;`
- 注意两个运算符中间不要有空格
```c
total += (sum + 100) / 2;   // total = total + (sum + 100) / 2;
total *= sum + 12;          // total = total * (sum + 12);
total /= 12 + 6;            // total = total / (12 + 6);
```

**递增递减运算符**：
- `++` 和 `--` 是两个很特殊的单目运算符，算子还必须是变量，作用是给这个变量 +1 或 -1
- 下面三种写法等价：
```c
count++;
count += 1;
count = count + 1;
```
- 前缀和后缀：`a++` 的值是 a 加 1 以前的值，`++a` 的值是加了 1 以后的值；无论哪种，a 自己的值都加了 1
- 这两个运算符有其历史来源，可以单独使用，但不要组合进表达式：`++i++`、`i++++`、`a = b+=c++-d+--e/-f` 这类写法都没有意义
