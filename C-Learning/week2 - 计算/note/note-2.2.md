# 第二周：计算

## 2.2 表达式

**`/` 和 `%` 的用途**
以计算时间差为例：
`t / 60` 取小时部分，`t % 60` 取分钟部分，先把时间统一换成分钟再进行计算。

**小套路**
交换两个变量a,b可以引入中间变量t：
```c
int t = a; a = b; b = t;
```

**`++` 和 `--`**：
- `count++`、`count += 1`、`count = count + 1` 三者等价
- `a++` 的值是加 1 **以前**的值，`++a` 的值是加 1 **以后**的值；不管哪种写法，a 最后都加了 1
- 只单独使用，不要塞进表达式，写成`a = b+=c++-d+--e/-f` 这样的复杂形式

**别写复杂表达式**
像 `result = (result = result * 2) * 6 * (result = 3 + result);` 很容易读错，拆成几条语句写。
