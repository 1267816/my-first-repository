# 第二周：计算

## 2.1 变量

**为什么需要变量**：
- 要能在程序运行时输入那个数字，然后计算输出结果，需要三件事：
  1. 有地方放输入的数字
  2. 有办法输入数字
  3. 输入的数字能参与计算
- 变量就是一个保存数据的地方。用变量保存了数据，它才能参加到后面的计算中，比如计算找零

**变量定义**：
- 一般形式：`<类型名称> <变量名称>;`
```c
int price;
int amount;
int price, amount;
```
- `int price = 0;` 这一行定义了一个变量：名字是 price，类型是 int，初始值是 0

**变量的名字**：
- 变量的名字是一种“标识符”，用来识别这个和那个
- 构造规则：只能由字母、数字和下划线组成；数字不可以出现在第一个位置；C 语言的关键字（保留字）不可以当标识符
- C 的保留字（auto、break、case、char、const……）不需要背诵

**赋值和初始化**：
- `price = 0` 是一个式子，这里的“=”是赋值运算符，表示将“=”右边的值赋给左边的变量
- 和数学不同：数学里 `a=b` 表示 a 和 b 的值一样（静态的关系），程序里 `a=b` 是要求计算机做一个动作——把 b 的值赋给 a
- 数学里 `a=b` 和 `b=a` 等价，程序里这两者的意思完全相反
- 初始化：赋值发生在定义变量的时候
- 定义时也可以只给其中一个变量赋初值：`int price = 0, amount = 100;`
- C 语言没有强制要求所有变量都在定义的地方初始化，但**所有的变量在第一次被使用（出现在赋值运算符的右边）之前应该被赋值一次**

**读整数**：
```c
scanf("%d", &price);
```
- 要求 scanf 读入下一个整数，读到的结果赋值给变量 price
- 小心 price 前面的 `&`

**表达式**：
- 有运算符的式子就叫做表达式，例如 `price = 0;` 和 `change = 100 - price;`

**变量类型**：
- C 是一种有类型的语言：所有变量在使用之前必须定义或声明，所有变量必须具有确定的数据类型
- 数据类型表示变量中可以存放什么样的数据，变量中只能存放指定类型的数据，程序运行过程中也不能改变变量的类型
- ANSI C 只能在代码开头的地方定义变量，C99 允许随用随定义（现在的 Dev-C++ 默认支持 C99，这样写不会报错）

**常量**：
- 固定不变的数叫常数，直接写在程序里叫直接量（literal）
- 更好的方式是定义一个常量变量：
```c
const int AMOUNT = 100;
int change = AMOUNT - price;
```
- `const` 是一个修饰符，加在 int 前面，给这个变量加上“不变的”属性：一旦初始化，就不能再修改
- 如果试图对它做修改（把它放在赋值运算符左边），编译器会报错指出来

**小技巧**：
- 程序要求读入多个数字时，可以在一行输入、中间用空格分开，也可以分多行输入
- scanf 的格式字符串中有几个 `%d`，它就等待用户输入几个整数

**计算身高（整数除法的坑）**：
- 题目：(5 + 7 ÷ 12) × 0.3048 = 1.7018 米，但程序总是输出 1.524 米
- 原因：两个整数运算的结果只能是整数，`inch / 12` 里 inch 是 int，所以 7/12 直接变成 0
- `10/3*3` 的结果是 9 而不是 10；`10` 和 `10.0` 在 C 中是完全不同的数
- 改法一：把除数写成浮点数
```c
(foot + inch / 12.0) * 0.3048;
```
  当浮点数和整数放到一起运算时，C 会将整数转换成浮点数，然后进行浮点数的运算
- 改法二：把 inch 的定义从 `int` 换成 `double`

**浮点数**：
- 带小数点的数值。浮点这个词的本意是指小数点是浮动的，是计算机内部表达非整数（包含分数和无理数）的一种方式
- `double` 是“双精度浮点数”，`float` 是单精度浮点数

**数据类型小结**：

| 数据 | 类型 | printf | scanf |
| --- | --- | --- | --- |
| 整数 | `int` | `%d` | `%d` |
| 带小数点的数 | `double` | `%f` | `%lf` |

- 整数类型不能表达有小数部分的数，整数和整数的运算结果还是整数
- 计算机里会有“纯粹的整数”这种奇怪的东西，是因为整数的运算比较快，而且占地方也小

**思考**：
- 幻灯片问“如果输入的不是整数会怎样？”——scanf 读不到匹配的内容，price 会保持原来的值，那段输入会留在输入缓冲区里，后面的 scanf 接着读，所以输入格式和格式串要对应好
- 幻灯片问“如果没有初始化？”——局部变量的值是内存里遗留的随机内容，结果不可预测。所以变量用之前一定要先赋值
