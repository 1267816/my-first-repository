# 第二周：计算

## 2.1 变量

**变量**：
保存数据的地方，存进去才能参与计算。定义写 `<类型名称> <变量名称>;`，定义时赋值就是初始化。

==**赋值不是数学等号**==：
- 数学里 `a=b` 表示相等，程序里 `a=b` 是动作——把 b 的值赋给 a
- 所以 `a=b` 和 `b=a` 意思完全相反
- 变量第一次被使用之前一定要赋值，没初始化的变量里是随机值

==**scanf 别漏 &**==：
```c
scanf("%d", &price);
```

==**整数除法的坑**==：
- 整数和整数运算的结果还是整数：`7 / 12` 得 0，所以身高换算 `(5 + 7/12) * 0.3048` 永远是 1.524
- `10/3*3` 得 9 不是 10；`10` 和 `10.0` 在 C 里是完全不同的数
- 想要小数结果：写成 `12.0`，或者干脆把变量定义成 `double`

==**类型和格式符**==：
整数用 `int`、`%d`；带小数的数用 `double`，printf 用 `%f`，**scanf 要用 `%lf`**=。

**常量**：`const int AMOUNT = 100;` 定义后**不能再改**，写在赋值号左边编译器会报错。

**变量名**：只能由字母、数字、下划线组成，数字不能放第一位，不能用关键字。
