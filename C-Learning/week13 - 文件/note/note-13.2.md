# 第十三周：文件

## 13.2 位运算

### 13.2.1

**按位运算**

C有这些按位运算的运算符：

- 按位的与`&`
- 按位的或`|`
- 按位取反`~`
- 按位的异或`^`
- 左移`<<`
- 右移`>>`

前四个可以理解成逻辑运算（不是C语言里的），不过它们运算的对象是一位。

**按位与`&`**

如果`(x)ᵢ == 1`并且`(y)ᵢ == 1`，那么`(x & y)ᵢ = 1`；否则的话 `(x & y)ᵢ = 0`。
按位与常用于两种应用：

  - 让某一位或某些位为0：`x & 0xFE`
    因为0xFE转成二进制是1111 1110
  - 取一个数中的一段：`x & 0xFF`
    因为0xFF转成二进制是1111 1111

**按位或`|`**

如果`(x)ᵢ == 1`或`(y)ᵢ == 1`，那么`(x | y)ᵢ = 1`；否则的话，`(x | y)ᵢ == 0`。
按位或常用于两种应用：

  - 使得一位或几个位为1：`x | 0x01`
    因为0x01转成二进制是0000 0001
  - 把两个数拼起来：`0x00FF | 0xFF00`
    因为0x00FF是0000 0000 1111 1111
    0xFF00是1111 1111 0000 0000

**按位取反`~`**

`(~x)ᵢ = 1 - (x)ᵢ`，对于每一位，把1位变0，0位变1。
想得到全部位为1的数：`~0`。
7的二进制是0111，`x | 7`使得低3位为1，而`x & ~7`，就使得低3位为0。
注意：按位取反和算补码不同，相当于算反码。

**逻辑运算vs按位运算**

对于逻辑运算，它只看到两个值：0和1。
可以认为：逻辑运算相当于把所有非0值都变成1，然后做按位运算。

  - `5 & 4 --> 4` 而 `5 && 4 --> 1 & 1 --> 1`
  - `5 | 4 --> 5` 而 `5 || 4 --> 1 | 1 --> 1`
  - `~4 --> 3` 而 `!4 --> !1 --> 0`

在上面的例子中，注意：左边的是按位运算，右边的是逻辑运算。
不过实际上，对4取反的结果应为5。

**按位异或`^`**

如果 `(x)ᵢ == (y)ᵢ`，那么 `(x ^ y)ᵢ = 0`；否则的话，`(x ^ y)ᵢ == 1`。
也就是说，如果两个位相等，那么结果为0；不相等，结果为1。如果x和y相等，那么 `x ^ y` 的结果为0。
对一个变量用同一个值异或两次，等于什么也没做：`x ^ y ^ y --> x`。

### 13.2.2

**左移`<<`**

`i<<j`表示把i的二进制位整体左移j位，右边补0。如果溢出，会被截断。
`x<<=n`等价于`x*=2^n`。

**右移`>>`**

`i>>j`表示把i的二进制位整体右移j位。

向左移不管符号位，向右移要管符号位。
==移位的位数不要用负数！！！==
对于小于int的类型，会先提升为int再移位，结果类型通常是int。

### 13.2.3

**输出一个数的二进制**

```c
unsinged mask=1u<<31;
// 把最末位的1向左推了31位，注意这里的u表示无符号数，这样才能向左推31位。
for ( ;mask;mask>>=1) {
  // mask非0就继续把它右移一位
  printf("%d",number&mask?1:0);
  // 输出number的对应位
}
```

### 13.2.4

**位段**

把一个int的若干位组合成一个结构。

```c
struct {
  unsigned int leading:3;
  ...
}
```

注意：“3”代表的是bit。如果结构里的bit加起来大于32，则会使用多个int。
