# 第十三周：文件

## 13.1 文件

### 13.1.1

**格式化的输入输出**

printf：`%[flags][width][.prec][hlL]type`

| Flag | 含义 |
| :--- | :--- |
| - | 左对齐 |
| + | 在前面放 + 或 - |
| (space) | 正数留空 |
| 0 | 0填充 |

| width 或 prec | 含义 |
| :--- | :--- |
| number | 最小字符数 |
| * | 下一个参数是字符数 |
| .number | 小数点后的位数 |
| .* | 下一个参数是小数点后的位数 |

prec表示精度。
星号表示动态指定，宽度或精度不写死在代码里，而是由后面的变量传入。例如：
`printf("%*d",5,123);`中的5就传给了星号作为宽度。

| 类型修饰`[hlL]` | 含义 |
| :--- | :--- |
| hh | 单个字节 |
| h | short |
| l | long |
| ll | long long |
| L | long double |

“单个字节”的含义是只截取这个数（转为2进制）的最后8位，并输出。

| type | 用于 | type | 用于 |
| :--- | :--- | :--- | :--- |
| i 或 d | int | g | float |
| u | unsigned int | G | float |
| o | 八进制 | a 或 A | 十六进制浮点 |
| x | 十六进制 | c | char |
| X | 字母大写的十六进制 | s | 字符串 |
| f 或 F | float, 6 | p | 指针 |
| e 或 E | 指数 | n | 读入/写出的个数 |

`%n`比较特殊。它不输出内容，而是把已经打印出的字符个数，存放到对应的参数指针里。例如：

```c
int num;
printf("%d%n\n",12345,&num);
printf("%d",num);
```

第二行就会输出5。

scanf：`%[flag]type`

| flag | 含义 |
| :--- | :--- |
| * | 跳过 |
| 数字 | 最大字符数 |
| hh | char |
| h | short |
| l | long, double |
| ll | long long |
| L | long double |

“跳过”的含义是跳过读取到的数据。例如：
`scanf("%d %*d %d",&a,&b);`
输入`1 2 3`时，2会被跳过，a得到1，b得到3。

| flag | 含义 |
| :--- | :--- |
| * | 跳过 |
| 数字 | 最大字符数 |
| hh | char |
| h | short |
| l | long, double |
| ll | long long |
| L | long double |

| type | 用于 | type | 用于 |
| :--- | :--- | :--- | :--- |
| d | int | s | 字符串（单词） |
| i | 整数，可能为十六进制或八进制 | [...] | 所允许的字符 |
| u | unsigned int | p | 指针 |
| o | 八进制 | | |
| x | 十六进制 | | |
| a,e,f,g | float | | |
| c | char | | |

**`[^.]`**

读取字符，直到遇到方括号内的字符（或集合）为止。`%[^,]` 表示一直读取，直到遇到逗号 `,` 才停止。读取到的内容会作为字符串存入变量。
`%*[^,]` 表示跳过前面的字符，直到遇到逗号。
一种应用如下：

```c
// 需要读取的GPS数据（以逗号分隔）：
// $GPRMC,004319.00,A,3016.98468,N,...
// 用下面的scanf进行读取：
scanf("%*[^,],%[^,],%[^,],...", sTime, sAV, sLati, ...);
```

***printf和scanf的返回值**

printf：输出的字符总数，包括空格、换行符等；
scanf：读入的项目数，即成功匹配并且赋值的变量个数。

在要求严格的程序中，应该判断每次调用scanf或printf的返回值，从而了解程序运行中是否存在问题。
