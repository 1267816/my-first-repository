# 第五周：循环控制

## 5.2 循环控制

### 5.2.1

**break 和 continue**
- break：跳出循环
- continue：跳过循环这一轮剩下的语句进入下一轮

**讨论**
在写判断素数的代码时，老师提到了一种“聪明”的做法：可以不设`isPrime`，直接利用循环出口处循环变量和终点值的关系来判断循环是否break了。这种做法是不合适的，为什么？
```c
#include <stdio.h>
int main(){
	int x;
	scanf("%d",&x);
	int i;
	int isPrime=1;  // x是素数
	for (i=2;i<x;i++) {
		if (x%i==0) {
			isPrime = 0;
			break;
		}
	}
	if (isPrime==1) { 
//这里也能判断i是否等于x，但不好
		printf("是素数\n");
	} else {
		printf("不是素数\n");		
	}
	return 0;
}
```
- 可读性差
- 过度依赖循环的具体写法，如果把循环写成只试除到x的平方根，就会出问题
- 不符合“循环变量只在循环内使用”的习惯

### 5.2.2
对prime.c进行修改，得到能输出2-100内所有素数的代码：
```c
#include <stdio.h>
int main(){
	int x;
	int i; // x是素数
	for (x=2;x<100;x++) {
		int isPrime=1;
		for (i=2;i<x;i++) {
			if (x%i==0) {
				isPrime = 0;
				break;
			}
		}
		if (isPrime==1) {
			printf("%d ",x);
		}
	}
	printf("\n");
	return 0;
}
```
**易错点**
`isPrime`必须放在第一个for循环里面，才能让每次判断x是否为素数时，`isPrime`始终被正确地初始化为1。

### 5.2.3

**break和continue**：
- 只能对它所在的那层循环做
  
那么，就会自然引出一个问题：怎么跳出所有循环呢？
```c
int exit;
for (...) {
    for (...) {
        ...
        if (...) {
        exit=1;
        break;
        }
    }
    if (exit==1) {
        break;
    }
}
```
这叫做**接力break**。
除此之外，还有另一种手段**goto**：
```c
for (...) {
    for (...) {
        ...
        if (...) {
            ...
            goto out;
        }
    }
}
out:
```
在这里，`goto out:`和`out:`可以理解成“传送门”，这使得代码可以任意跳转。
但是，一些C语言教材不鼓励用`goto`，原因如下：
1. 结构化程序设计原则
结构化程序强调用顺序、选择、循环三种结构表达逻辑，尽量做到单入口、单出口。`goto` 可以向前向后任意跳，容易形成“面条代码”，让控制流不再局部、清晰。
2. 可读性
“接力 break”通常是用一个标志变量，每层循环判断后逐层 `break`。虽然代码长，但退出条件写在每层循环里，读者容易跟踪。goto 的标签可能离得很远，跳转路径不直观，而在多个标签时会更乱。
3. 可维护性
如果后来增加循环层、修改退出条件，接力 break 的改动比较局部；而 goto 标签和跳转点需要同步维护，容易漏掉清理逻辑或引入错误。
4. 可验证性
结构化控制流容易画流程图、做静态分析、推理正确性；goto 会让控制流图复杂化，增加测试和证明难度。
