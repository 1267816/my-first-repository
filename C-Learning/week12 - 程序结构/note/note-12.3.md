# 第十二周：程序结构

## 12.3 大程序结构

### 12.3.1

**多个.c文件**

- main()里的代码太长了，适合分成几个函数
- 一个源代码文件太长了，适合分成几个文件

但是，两个独立的源代码文件不能编译形成可执行的程序。怎么办呢？

**项目**

在Dev C++中新建一个项目，然后把几个源代码文件加入进去。
对于项目，Dev C++的编译会把一个项目中所有的源代码文件都编译后，链接起来。
有的IDE有分开的编译和构建两个按钮，前者是对单个源代码文件编译，后者是对整个项目做链接。

==注意：路径一定要是纯英文！！！==
在这个目录的video文件夹下，max项目编译失败了；但是换到C-Learning/project-test/max下，就成功了。

**编译单元**

一个.c文件是一个编译单元，编译器每次编译只处理一个编译单元。

### 12.3.2

**头文件**

把函数原型放到一个头文件（以.h结尾）中，在需要调用这个函数的源代码文件（.c文件）中`#include`这个头文件，就能让编译器在编译的时候知道函数的原型。
注意，这里不用尖括号包住头文件，而是用双引号。
这就引出了我们的下一个问题：

**`""`还是`<>`**

`#include`有两种形式来指出要插入的文件：

- `""`要求编译器首先在当前目录（.c文件所在的目录）寻找这个文件，如果没有，到编译器指定的目录去找
- `<>`让编译器只在指定的目录去找

编译器自己知道自己的标准库的头文件在哪里。
环境变量和编译器命令行参数也可以指定寻找头文件的目录。

因此，自己的头文件一般用双引号。

**`#include`的误区**

`#include`不是用来引入库的。
`<stdio.h>`里只有printf的原型，printf的代码在另外的地方，某个.lib中。
现在的C语言编译器默认会引入所有的标准库，而`#include <stdio.h>`只是为了让编译器知道printf函数的原型，保证你调用时给出的参数值是正确的类型。

**头文件**

在使用和定义这个函数的地方都应该`#include`这个头文件。
一般的做法：任何.c都有对应的同名的.h，把所有对外公开的函数的原型和全局变量的声明都放进去。

**不对外公开的函数**

在函数（全局变量）前面加上static，就使得它成为只能在所在的编译单元中被使用的函数（全局变量）。

### 12.3.3

**变量的声明**

`int i;`是变量的定义；
`extern int i;`是变量的声明。

**声明和定义**

声明是不产生代码的东西：

- 函数原型
- 变量声明
- 结构声明
- 宏声明
- 枚举声明
- 类型声明
- inline函数

定义是产生代码的东西：

- 函数
- 全局变量

**头文件**

只有声明可以被放在头文件中，定义不能放。
否则会造成一个项目中多个编译单元里有重名的实体，如：

假设在max.h里写了一个全局变量`int cnt=0;`，
然后main.c里和max.c里都写了`#include "max.h"`。
那么，根据“完全的文本替换”，在main.c和max.c编译后，各自都有一个cnt变量。
最后，链接器链接时，发现有两个cnt，就会出现“重复定义”的报错。

> 某些编译器允许几个编译单元中存在同名的函数，或者用weak修饰符来强调这种存在。

**标准头文件结构**

即使只放声明，如果多次被`#include`，也会出问题。
这时，我们就要使用标准头文件结构：

```c
#ifndef __LIST_HEAD__
#define __LIST_HEAD__

#include "node.h" // 自己的代码

typedef struct _list { //
    Node* head; //
    Node* tail; //
} List; //

#endif
```

它运用条件编译和宏，保证这个头文件在一个编译单元中只会被`#include`一次。
`#pragma once`也能起到相同的作用，但是，不是所有的编译器都支持。

注意：自己写的宏，

- 千万不要写`__LIST_HEAD__`这样的双下划线开头
这是C编译器、操作系统和标准库的专属
- 尽量不要写`_List`这样的单下划线+大写字母开头
这是留给系统标准库用的
- 只能在局部写`_name`这样的单下划线+小写字母开头
不能在函数外部（全局）用，因为可能和系统隐藏变量冲突

应该怎么命名？

1. 写头文件保护的宏
   应该写`LIST_HEAD_H`或`MYPROJECT_LIST_HEAD_H`
   公式：`全大写文件名_H`或`项目名_文件名_H`

2. 定义普通宏
   应该写`#define MAX_BUFFER_SIZE 1024`
   公式：全部大写，单词之间用单下划线连接

3. 定义普通变量和函数
   不要以下划线开头，用英文字母开头即可
