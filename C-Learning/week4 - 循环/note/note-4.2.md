# 第四周：循环

## 4.2 循环应用

**两个小套路**
- 计算之前先保存原始的值，后续可能要输出
- 要模拟很大次数的循环，先模拟较少的次数，再推断结果

**猜数游戏的随机数生成**
- `rand()` 每次给一个随机整数，`x%n` 的结果在区间[0,n-1]内，所以 `rand()%100+1`就能够正好在区间[1,n]

**算平均数**
注意 count 从 0 开始还是从 -1 开始
```c
int sum = 0, count = -1, number = 0;
while (number!=-1) {
    sum+=number;
    count++;
    scanf("%d", &number);
}
```
- 循环是先累加、再读下一个数，==所以第一圈会把 number 的初始值 0 也算进去，count 从 -1 起步正好抵消==
- 求平均时要转成浮点，否则整数除法会把小数丢掉

**整数分解**
`% 10` 得到个位数，`/ 10` 去掉个位数，反复做就能从低位到高位取出每一位。
