# 第四周：循环

## 4.1 循环

**while**
条件满足时，不断重复循环体。
- 循环开始前先判断，所以**可能一次都不执行**
- 循环体内**必须有机会改变条件里的变量**，否则就是死循环
```c
while (条件) {
    循环体
}
```

**do-while**
先执行一圈再判断，**至少执行一次**。
```c
do {
    循环体
} while (条件);
```
```c
do {
    x/=10;
    n++;
} while (x>0);
```
- 数位数这个题用 do-while 更合适：输入 0 时 0 也是一位数，而使用while 写法会算成 0 位，所以需要至少执行一次

**调试和验证**
- 人脑模拟：在纸上列出所有变量，跟着程序一行行更新它们的值
- 测试边界数据：个位数、10、0、负数
- 结果不对时，在关键位置插 printf 打印变量
