# 第四周：循环

## 4.1 循环

**数几位数的问题**：
- 程序要读入一个 4 位以下（含 4 位）的正整数，然后输出这个整数的位数，例如输入 352 输出 3
- 人的方式：眼睛一看就知道了
- 计算机的方式：判断数的范围来决定位数，`352 ∈ [100, 999]` 所以是 3 位
- 因为题目明确了是 4 位及以下，可以从高往低判断，这样连上限都不用判断；反过来不行
- 问题：任意范围的正整数怎么办？

**换个方式想：数数**：
- 352 好数，那么 123812843267518273618273612675317 是几位？
- 人怎么数：从左往右数，一次划掉一个数字
- 计算机怎么划掉那个数字？`x / 10` 可以去掉最右边的数
- 不断地划，直到没数可以划，同时在这个过程中计数

**while 循环**：
```c
while ( x > 0 ) {
    x /= 10;
    n++;
}
```
- 把 while 翻译作“当”，那么一个 while 循环的意思就是：当条件满足时，不断地重复循环体内的语句
- 循环执行之前判断是否继续循环，所以有可能循环一次也没有被执行
- 条件成立是循环继续的条件
- **循环体内要有改变条件的机会**（否则条件永远成立，循环停不下来）
- 对比一下 if 和 while：`if ( x > 0 ) { x /= 10; n++; }` 只做一次，换成 while 就会一直做

**验证程序**：
- 人脑模拟计算机的运行：在纸上列出所有的变量，随着程序的进展不断重新计算变量的值，程序结束时，表格最下面的就是程序的最终结果
- 测试程序常使用边界数据，例如有效范围两端的数据、特殊的倍数
  - 个位数
  - 10
  - 0
  - 负数

**调试**：
- 在程序适当的地方插入 printf，输出变量的内容
- 幻灯片特别提醒：别拿 123812843267518273618273612675317 去试

**do-while 循环**：
```c
do {
    x /= 10;
    n++;
} while ( x > 0 );
```
- 在进入循环的时候不做检查，而是在执行完一轮循环体的代码之后，再来检查循环的条件是否满足
- 条件满足则继续下一轮循环，不满足则结束循环
- 语法格式：
```c
do {
    <循环体语句>
} while ( <循环条件> );
```
- 和 while 循环的区别：do-while 在循环体执行结束的时候才判断条件，也就是说**无论如何循环都会执行至少一遍**

**数位数的算法**（用 do-while 写）：
1. 用户输入 x
2. 初始化 n 为 0
3. `x = x / 10`，去掉个位
4. `n++`
5. 如果 x > 0，回到第 3 步
6. 否则 n 就是结果

```c
int x;
scanf("%d", &x);
int n = 0;
do {
    x /= 10;
    n++;
} while ( x > 0 );
printf("%d", n);
```

**思考**：
- 为什么数位数用 do-while 更合适？——输入 0 的时候，0 其实是一位数。while 写法里 `x > 0` 一开始就不成立，会得到 0 位；do-while 先执行一次，能正确地算出 1 位
- 幻灯片问“如果没有外面的运算？”——循环体内必须先改变条件里的变量，否则循环会一直执行下去
