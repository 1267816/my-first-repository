# 各周 `module/` 放什么

> **代码已经定下来了**：算法模板全部放在 [`ACM-ICPC/templates/`](../ACM-ICPC/templates/README.md)，按四批分文件夹（现在是 22 个占位文件，只有文件头）。
> `weekN/module/` 只放**课程周内专用**的模块：取位、位数遍历、gcd 这类一课里讲完的东西，不再复制模板。
> 本文件回答两个问题：为什么这么分、某一周的语法最早能写哪些算法。清单与批次在 ACM 侧维护，这边只引。

## 原则：按最低知识范围归位

一个模板只允许用「学完某一周就能写」的语法，**最低周次**就写在文件头第一行。
这样回头看时，每份模板都对应一段真实学过的内容，不用猜它用了哪些语法。

举几个会放错的例子：

- 排序、计数桶、前缀和、筛法、二分都要数组 → 最早 `week8`，按 week5 的语法写就超纲了；
- 双指针、栈、队列要指针或数组 → `week9`；
- 递归最早是 `week7`（函数那一周）；
- 快速幂、负数取模、类型边界要 `long long` → `week6`。

## 想从 module 用模板怎么办

写一行指针就行，不要复制代码：

```c
// 前缀和模板见 ACM-ICPC/templates/批2-拉开差距/01-prefix-sum-1d.c
```

复制一份的后果是两边慢慢走样，改了一处忘了另一处。

## 课程模块长什么样

课程模块（`weekN/module/`）跟模板共用一套文件头，只是内容更窄：

```text
// 名字：取一个正整数的每一位
// 最低周次：week5
// 什么时候用：按位处理数字，题面要求从高位开始输出
// 复杂度：O(位数)
// 易错点：先算出最高位的 10 的幂；注意 0 单独处理
```

单文件、能直接 `gcc x.c -o x.exe -fexec-charset=GBK` 编过并跑出结果；四行文件头不许省。
