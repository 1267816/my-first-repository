# 第三周：判断

## 3.1 判断

**if 语句**
```c
if (条件) { 
    ... 
    }
```
括号里的结果不是 0 就执行大括号里的语句。
- if 那一行末尾**没有分号**
- 不加大括号时，只有紧跟着 if 的那一条语句受控制

**关系运算的结果==只有1或0两种可能==，1代表真，0代表假**
```c
printf("%d\n", 5 == 3);   // 会输出0
```

**优先级和结合顺序**
- 关系运算比算术运算低、比赋值高
  `7 >= 3 + 4` 先算加法
- `==` 和 `!=` 比其他关系运算还低
  连续的关系运算只是从左到右算
  - `6 > 5 > 4` → `1 > 4` → 0，**不是数学里的连不等式**
  - `a == b > 0` → `a == (b > 0)`

**注释**
- `//` 单行
- `/* */` 多行，也能写在行内
- 不进入编译，增强代码可读性
