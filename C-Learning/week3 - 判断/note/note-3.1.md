# 第三周：判断

## 3.1 判断

**为什么需要判断**（计算时间差）：
- 直接分别减小时和分钟会出现分钟借位，例如 1 点 40 分和 2 点 10 分
- 借位的表现是：分钟相减的结果小于 0
- 所以可以先用分别减的方案，然后判断有没有出现借位
```c
int im = minute2 - minute1;
if ( im < 0 ) {
    ...
}
```

**if 语句**：
```c
if ( 条件成立 ) {
    ...
}
```
- 一个基本的 if 语句由一个关键字 `if` 开头，跟上括号里的一个表示条件的逻辑表达式，然后是一对大括号 `{}` 之间的若干条语句
- 如果条件的结果不是零，就执行后面那对大括号中的语句；否则跳过这些语句不执行，继续执行下面的其他语句
- 注意下面这种写法：if 这一行结束时没有表示语句结束的“;”，后面的赋值语句写在 if 的下一行并缩进，说明这条语句是 if 的一部分，由 if 决定它是否被执行
```c
if ( total > amount )
    total += amount + 10;
```

**关系运算符**：

| 运算符 | 意义 |
| --- | --- |
| `==` | 相等 |
| `!=` | 不相等 |
| `>` | 大于 |
| `>=` | 大于或等于 |
| `<` | 小于 |
| `<=` | 小于或等于 |

- 计算两个值之间的关系，所以叫做关系运算
- 当两个值的关系符合关系运算符的预期时，结果为整数 1，否则为整数 0
```c
printf("%d\n", 5 == 3);   // 0
printf("%d\n", 5 > 3);    // 1
printf("%d\n", 5 <= 3);   // 0
```

**优先级**：
- 所有的关系运算符的优先级比算术运算低，但是比赋值运算高
```c
7 >= 3 + 4;
int r = a > 0;
```
- 判断是否相等的 `==` 和 `!=` 的优先级比其他关系运算符低，而连续的关系运算是从左到右进行的
```c
5 > 3 == 6 > 4;   // 1 == 1 → 1
6 > 5 > 4;        // 1 > 4 → 0，不是数学里的连不等式
a == b == 6;      // (a == b) == 6
a == b > 0;       // a == (b > 0)
```

**找零计算器**：
- 用户做两个操作：输入购买的金额、输入支付的票面
- 程序根据用户的输入做出相应的动作：计算并打印找零，或者告知用户余额不足以购买
- 从程序的角度看就是：读用户的两个输入，进行一些计算和判断，最后输出结果
- 程序里用 `//` 把代码分成了三个部分：初始化、读入金额和票面、计算并打印找零

**注释**：
- 以两个斜杠 `//` 开头的注释是单行注释
- 延续数行的注释用多行注释：一对字符序列 `/*` 开始，`*/` 结束，也可以用于一行内的注释
```c
int ak = 47 /* 36 */, y = 9;
```
- 注释对程序的功能没有任何影响，但能让程序更容易被人类读者理解

**if-else**：
```c
if ( bill >= price ) {
    // 计算并打印找零
} else {
    // 告知余额不足
}
```
- `else` 的意思是“否则的话”
- 判断票面够不够时画流程图会更容易看清楚：条件成立走一条路，不成立走另一条路
- 如果 if 后面还有语句，它们在 if 结束后会执行，**无论条件如何**

**比较两个数的大小**：
- 只写 `if ( a > b ) { max = a; }` 是不够的：当 a > b 的条件不成立时，程序就结束了，max 没有得到值
- 方案一：再加一个判断处理 b 大于 a 的情况
- 方案二：用 else 处理另一种情况
