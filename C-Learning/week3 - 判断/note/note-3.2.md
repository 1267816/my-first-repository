# 第三周：判断

## 3.2 分支

**else 总是和最近的 if 匹配**
- 缩进**不能**暗示匹配关系（不是python），要让 else 跟外面的 if 配对就需要大括号：
```c
if ( code == READY ) {
    if ( count < 20 )
        printf("一切正常\n");
} else
    printf("继续等待\n");
```
- 所以 if/else 建议**总是加大括号**，哪怕只有一条语句

**级联 if-else if**
适合分段函数这类多段判断。
- **单一出口**：把结果算到变量里最后统一打印，比每个分支各打印一次可读性更强

**if 的四个常见错误**：
- 忘了大括号，这样只有紧跟 if 的那条语句受控制
- `if (age>60);` 多了个分号，这样会变成空语句
- `if (a=b)` 把 `==` 写成 `=`，这样会变成赋值，结果非零就成立
- else 匹配到了不该匹配的 if，即大括号位置不正确

**switch-case**
- 控制表达式只能是整数型的结果，case 后面必须是常量，这里的常量也可以是能算出常量的表达式，如`1+1`
- case 只是"路标"，匹配后一直往下执行，**遇到 break 才停**；没有 break 会继续执行下一个 case 的语句
- 都不匹配就执行 default，没有 default 就什么都不做
- 多个 case 可以共用一段代码
